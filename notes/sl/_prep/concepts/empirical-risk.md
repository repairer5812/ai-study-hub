## 왜 필요한가

true risk는 $P_{XY}$ 를 몰라서 계산할 수 없었습니다. 손에 있는 것은 $P_{XY}$ 에서 나온 표본 $n$ 개입니다. 모르는 분포의 평균이 필요한데 그 분포에서 나온 표본이 있다면 할 수 있는 일은 하나입니다. 모평균 자리에 표본평균을 넣습니다.

이렇게 바꾼 문제가 실제 학습에서 푸는 문제입니다. 그래서 "바꿔도 되는가"를 따로 물어야 합니다.

## 정의와 수식

데이터 $D = \{(\mathbf{x}_i, y_i)\}_{i=1}^{n}$ 위에서 손실을 평균한 값을 empirical risk라고 부릅니다.

$$
\mathcal{L}(h; D) = \frac{1}{n}\sum_{i=1}^{n} \ell(y_i, h(\mathbf{x}_i))
$$

식을 읽는 법 세 가지입니다.

- $h$ 의 함수입니다. $h$ 를 바꾸면 값이 바뀌고 그 값을 줄이는 쪽으로 $h$ 를 바꾸는 것이 학습입니다. $h$ 를 $\boldsymbol{\theta}$ 로 가리킨다면 $\mathcal{L}(\boldsymbol{\theta}; D)$ 라고 써도 같은 것입니다.
- 세미콜론 뒤의 $D$ 는 "어떤 데이터를 썼느냐에 따라 값이 달라진다"는 표시입니다. true risk에는 없던 것입니다.
- 학습 데이터 위에서 잰 값이므로 training error라고도 부릅니다.

뒤에 나오는 음의 로그우도 $\mathcal{L}_D(\boldsymbol{\theta})$ 도 같은 글자를 씁니다. 아래 첨자 $D$ 가 붙은 쪽이 음의 로그우도입니다.

**empirical risk minimization**

true risk 대신 empirical risk를 가장 작게 만드는 함수를 찾습니다. 찾는 범위는 가설 집합 $\mathcal{H}$ 입니다.

$$
\hat{h}^*_{\mathcal{H}} = \arg\min_{h \in \mathcal{H}} \mathcal{L}(h; D)
$$

기호가 세 겹입니다. 별표는 최소화로 얻었다는 뜻입니다. 모자는 데이터로 얻었다는 뜻입니다. 아래 첨자 $\mathcal{H}$ 는 그 집합 안에서 찾았다는 뜻입니다. 이 최소화를 푸는 일을 training이라고 부릅니다.

**무엇을 바꾸면 무엇이 되나**

ERM의 틀은 그대로 두고 $\ell$ 과 $\mathcal{H}$ 를 갈아 끼우면 익숙한 학습 문제가 나옵니다.

| 갈아 끼우는 것 | 고른 것 | 나오는 것 |
|---|---|---|
| 손실 $\ell$ | squared loss | 제곱 오차의 평균(MSE) |
| 손실 $\ell$ | absolute loss | 절댓값 오차의 평균(MAE) |
| 손실 $\ell$ | zero-one loss | 학습 데이터의 error rate |
| 가설 집합 $\mathcal{H}$ | 선형 모형 | 계수 $d+1$ 개를 찾는 문제 |
| 가설 집합 $\mathcal{H}$ | 신경망 | 같은 문제이고 찾을 매개변수만 훨씬 많다 |

선형 모형의 학습과 신경망의 학습은 규모가 다를 뿐 같은 식을 풉니다.

**써도 되는 두 근거**

함수 $h$ 를 하나 정해 두었을 때 그 함수의 empirical risk는 true risk의 좋은 추정값입니다. 근거는 둘입니다.

| 근거 | 내용 | 말해 주는 것 |
|---|---|---|
| 불편 추정량 | 데이터를 뽑는 일을 여러 번 되풀이해 평균을 내면 $R(h)$ 와 같다 | 한쪽으로 치우쳐 있지 않다 |
| 큰 수의 법칙 | $n$ 이 커질수록 $\mathcal{L}(h; D)$ 가 $R(h)$ 에 가까워진다 | 표본이 많으면 한 번 뽑은 값도 믿을 만하다 |

둘은 서로를 채웁니다. 불편 추정량이라는 성질은 $n$ 이 1이어도 성립하지만 그때의 값 하나는 크게 흔들립니다. 큰 수의 법칙은 그 흔들림이 $n$ 과 함께 잦아든다고 말합니다. 반대로 표본이 적으면 empirical risk는 좋은 추정값이 아닙니다. 불편 추정량이라는 성질의 증명은 [다음 노드](map.html?s=sl&n=empirical-risk-unbiased)에 있습니다.

<div class="cal key">

**두 근거에는 같은 단서가 붙어 있습니다**

둘 다 데이터를 보기 전에 정해 둔 함수에 대한 말입니다. ERM은 데이터를 본 뒤에 함수를 고릅니다. 이 차이에서 [일반화 문제](map.html?s=sl&n=generalization)가 나옵니다.

</div>

## 흔한 오해

<div class="cal trap">

**ERM은 true risk가 가장 작은 함수를 찾아 준다**

ERM이 찾는 것은 가진 데이터 위에서 손실의 평균이 가장 작은 함수입니다. 그 함수의 true risk가 작다는 보장은 식 어디에도 없습니다. 둘이 가까워지려면 표본이 충분해야 하고 가설 집합이 지나치게 크지 않아야 합니다.

</div>

<div class="cal trap">

**불편 추정량이므로 표본이 적어도 empirical risk를 믿을 수 있다**

불편이라는 말은 여러 번 뽑은 평균이 맞는다는 뜻입니다. 지금 가진 한 번의 값이 가깝다는 뜻이 아닙니다. 한 번의 값이 가깝다고 말해 주는 것은 큰 수의 법칙이고 거기에는 $n$ 이 커야 한다는 조건이 붙습니다.

</div>

## 확인 질문

<div class="cal q">

데이터가 $(x, y) = (1, 1), (2, 3), (3, 2), (4, 6)$ 네 쌍이고 가설 집합에 함수가 둘뿐입니다. $h_a(x) = x$ 와 $h_b(x) = 1.5x$ 입니다.

- (가) squared loss로 두 함수의 empirical risk를 구하고 ERM이 고르는 함수를 적으세요.
- (나) absolute loss로 같은 일을 해 보세요.
- (다) 두 결과가 왜 다른지 한 문장으로 설명해 보세요.

</div>

<details class="solve">
<summary>답 보기</summary>

예측에서 정답을 뺀 값은 $h_a$ 가 $0, -1, 1, -2$ 이고 $h_b$ 가 $0.5, 0, 2.5, 0$ 입니다.

| | $h_a(x) = x$ | $h_b(x) = 1.5x$ | ERM의 선택 |
|---|---|---|---|
| squared loss | $(0 + 1 + 1 + 4)/4 = 1.5$ | $(0.25 + 0 + 6.25 + 0)/4 = 1.625$ | $h_a$ |
| absolute loss | $(0 + 1 + 1 + 2)/4 = 1$ | $(0.5 + 0 + 2.5 + 0)/4 = 0.75$ | $h_b$ |

(다) $h_b$ 는 세 점을 거의 맞추고 한 점에서 2.5만큼 크게 틀립니다. squared loss는 그 큰 오차 하나를 6.25로 무겁게 세므로 $h_b$ 를 버리고 absolute loss는 2.5로만 세므로 $h_b$ 를 고릅니다. 같은 데이터와 같은 가설 집합에서도 손실이 바뀌면 ERM의 답이 바뀝니다.

</details>
