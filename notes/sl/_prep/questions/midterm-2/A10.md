<section data-q="stem">

In mini-batch stochastic gradient descent, each update computes the gradient from a small subset of the training samples, so the parameters can be updated more frequently than in gradient descent that uses the entire dataset for every update.

</section>

<section data-q="ko">

mini-batch stochastic gradient descent 에서는 갱신할 때마다 학습 표본의 작은 일부로 gradient 를 계산한다. 그래서 갱신마다 데이터 전체를 쓰는 gradient descent 보다 매개변수를 더 자주 갱신할 수 있다.

</section>

<section data-q="answer">

**참.** 기본 gradient descent 는 한 번 옮길 때마다 표본 $n$ 개의 gradient 를 모두 계산합니다. 데이터가 크면 한 걸음이 느리고 메모리도 많이 듭니다.

mini-batch 방식은 표본의 일부만 골라 gradient 를 계산하고 바로 옮깁니다. 한 걸음의 계산이 가벼워져서 같은 양의 데이터를 보는 동안 매개변수를 여러 번 고칠 수 있습니다. 일부 표본으로 구한 gradient 는 전체로 구한 gradient 와 조금씩 다르므로 걸음마다 방향이 흔들립니다. stochastic 이라는 이름이 여기서 나옵니다.

갱신식의 꼴은 그대로입니다. $g(\mathbf{w}_t)$ 를 계산할 때 쓰는 표본의 범위만 달라집니다.

</section>
