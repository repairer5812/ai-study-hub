<section data-q="stem">

To learn a predictor from data, we first choose a type of model, for example the linear model $h(\mathbf{x}; \boldsymbol{\theta}) = \boldsymbol{\theta}^T\tilde{\mathbf{x}}$ with $\tilde{\mathbf{x}} = (1, x_1, \dots, x_d)^T$. Which statement about this choice is correct?

- (a) It fixes one particular function $h$, so the data are needed only to evaluate that function.
- (b) It fixes the loss function $\ell$, and the hypothesis class is then determined by the training data.
- (c) It fixes the hypothesis class $\mathcal{H}$, and learning then searches $\mathcal{H}$ for the best $\boldsymbol{\theta}$.
- (d) It guarantees good performance, since a linear model works well for every data distribution.

</section>

<section data-q="ko">

데이터로 예측기를 학습하려면 먼저 모형의 종류를 고릅니다. 예를 들어 $\tilde{\mathbf{x}} = (1, x_1, \dots, x_d)^T$ 로 두는 선형 모형 $h(\mathbf{x}; \boldsymbol{\theta}) = \boldsymbol{\theta}^T\tilde{\mathbf{x}}$ 를 고릅니다. 이 선택에 대한 설명으로 옳은 것은 무엇입니까?

- (a) 함수 $h$ 하나가 정해진다. 데이터는 그 함수를 평가하는 데만 쓰인다.
- (b) 손실 함수 $\ell$ 이 정해진다. 가설 집합은 그 뒤에 학습 데이터가 정한다.
- (c) 가설 집합 $\mathcal{H}$ 가 정해진다. 학습은 그 뒤에 $\mathcal{H}$ 안에서 가장 좋은 $\boldsymbol{\theta}$ 를 찾는다.
- (d) 좋은 성능이 보장된다. 선형 모형은 어떤 데이터 분포에서도 잘 맞기 때문이다.

</section>

<section data-q="answer">

**(c).** 모형의 종류를 정하면 찾으려는 함수의 꼴이 정해집니다. 그 꼴에서 $\boldsymbol{\theta}$ 를 바꿔 가며 만들 수 있는 모든 함수의 모임이 가설 집합 $\mathcal{H}$ 입니다. 학습은 그 안에서 손실을 가장 작게 하는 $\boldsymbol{\theta}$ 를 찾는 일입니다. 순서는 두 단계입니다. 먼저 $\mathcal{H}$ 를 고르고 그다음 $\mathcal{H}$ 안에서 가장 좋은 함수를 찾습니다.

- (a) 정해지는 것은 함수 하나가 아니라 함수의 꼴입니다. $\boldsymbol{\theta}$ 가 정해지기 전에는 어느 초평면인지 알 수 없고 그것을 데이터로 정합니다.
- (b) 손실 함수는 모형과 따로 고릅니다. 가설 집합을 정하는 것은 데이터가 아니라 모형의 선택입니다.
- (d) 모든 분포에서 잘 맞는 모형은 없습니다. 선형 모형을 고르는 것은 입력과 출력의 관계에 가정을 두는 일이고 그 가정이 데이터와 맞을 때만 성능이 좋습니다.

</section>
