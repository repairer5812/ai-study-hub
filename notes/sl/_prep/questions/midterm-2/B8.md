<section data-q="stem">

A classifier is usually not trained by running gradient descent directly on the zero-one loss $\mathbf{1}[y \neq h(\mathbf{x})]$. Which of the following is the reason?

- (a) The zero-one loss can take negative values, so it has no minimum.
- (b) The zero-one loss can be computed only when the distribution $P_{XY}$ is known.
- (c) The zero-one loss grows quadratically with the error, so the updates diverge.
- (d) The zero-one loss is piecewise constant in the parameters, so its gradient gives no direction of descent.

</section>

<section data-q="ko">

분류기를 학습할 때 zero-one loss $\mathbf{1}[y \neq h(\mathbf{x})]$ 에 gradient descent 를 바로 적용하는 일은 드뭅니다. 그 이유는 무엇입니까?

- (a) zero-one loss 는 음수가 될 수 있어서 최솟값이 없다.
- (b) zero-one loss 는 분포 $P_{XY}$ 를 알아야만 계산할 수 있다.
- (c) zero-one loss 는 오차의 제곱으로 커져서 갱신이 발산한다.
- (d) zero-one loss 는 매개변수에 대해 구간마다 값이 일정해서 gradient 가 내려갈 방향을 알려 주지 않는다.

</section>

<section data-q="answer">

**(d).** zero-one loss 는 맞으면 0, 틀리면 1입니다. 매개변수를 조금 움직여도 예측이 바뀌지 않으면 손실이 그대로입니다. 예측이 바뀌는 순간에는 0과 1 사이를 건너뜁니다. 매개변수의 함수로 보면 계단 모양입니다. 평평한 곳에서는 gradient 가 0이라 어느 쪽으로 가야 손실이 주는지 알 수 없습니다. 건너뛰는 곳에서는 미분이 되지 않습니다.

gradient descent 는 gradient 의 반대 방향으로 조금씩 옮기는 방법이라 손실이 연속이고 미분되어야 쓸 수 있습니다. 그래서 분류기는 zero-one loss 대신 매끄러운 손실로 학습합니다. 로지스틱 회귀가 우도에서 얻은 손실이 그런 예입니다.

- (a) zero-one loss 의 값은 0 아니면 1이라 음수가 될 수 없습니다.
- (b) 학습 데이터에서 틀린 비율을 세면 되므로 분포를 몰라도 계산할 수 있습니다. 계산은 되는데 gradient 로 줄일 수 없는 것이 문제입니다.
- (c) 오차의 제곱으로 커지는 것은 squared loss 입니다. zero-one loss 는 1보다 커지지 않습니다.

</section>
