<section data-q="stem">

Consider a thought experiment in which the true risks are known. The smallest true risk over all functions is $R^* = 0.12$. The hypothesis class contains only three functions, $\mathcal{H} = \{h_1, h_2, h_3\}$:

| | $h_1$ | $h_2$ | $h_3$ |
|---|---|---|---|
| empirical risk $\mathcal{L}(h; D)$ | $0.10$ | $0.22$ | $0.18$ |
| true risk $R(h)$ | $0.35$ | $0.20$ | $0.25$ |

Empirical risk minimization over $\mathcal{H}$ is run on the training set $D$. What are the estimation error and the approximation error?

- (a) Estimation error $0.15$ and approximation error $0.08$
- (b) Estimation error $0.08$ and approximation error $0.15$
- (c) Estimation error $0.23$ and approximation error $0.08$
- (d) Estimation error $0.25$ and approximation error $0.23$

</section>

<section data-q="ko">

true risk 를 안다고 가정하는 사고 실험입니다. 모든 함수 가운데에서 가장 작은 true risk 는 $R^* = 0.12$ 입니다. 가설 집합에는 함수가 셋뿐입니다. 세 함수의 empirical risk 와 true risk 는 표와 같습니다. 학습 데이터 $D$ 로 $\mathcal{H}$ 위에서 empirical risk minimization 을 했습니다. estimation error 와 approximation error 는 각각 얼마입니까?

</section>

<section data-q="answer">

**(a).** ERM 은 empirical risk 가 가장 작은 함수를 고릅니다. $0.10$ 인 $h_1$ 입니다. 그래서 $\hat{h}^*_{\mathcal{H}} = h_1$ 이고 $R(\hat{h}^*_{\mathcal{H}}) = 0.35$ 입니다. $\mathcal{H}$ 안에서 true risk 가 가장 작은 함수는 $h_2$ 이므로 $R^*_{\mathcal{H}} = 0.20$ 입니다.

$$
\begin{aligned}
&R(\hat{h}^*_{\mathcal{H}}) - R^*_{\mathcal{H}} = 0.35 - 0.20 = 0.15 \\
&R^*_{\mathcal{H}} - R^* = 0.20 - 0.12 = 0.08
\end{aligned}
$$

첫째 줄이 estimation error, 둘째 줄이 approximation error 입니다.

estimation error 가 생긴 까닭은 표에 보입니다. 학습 데이터에서 가장 좋아 보인 $h_1$ 이 분포 전체에서는 셋 가운데 가장 나쁩니다. 표본으로 골랐기 때문에 $\mathcal{H}$ 안의 가장 좋은 함수 $h_2$ 를 놓쳤습니다. approximation error 는 $\mathcal{H}$ 에 함수가 셋뿐이라 가장 좋은 $h_2$ 조차 $R^*$ 에 못 미쳐서 생깁니다.

- (b) 두 값을 맞바꿨습니다.
- (c) $0.23$ 은 두 오차를 더한 excess error $R(\hat{h}^*_{\mathcal{H}}) - R^* = 0.35 - 0.12$ 입니다.
- (d) $0.25$ 는 $h_1$ 의 true risk 와 empirical risk 의 차이 $0.35 - 0.10$ 이고 $0.23$ 은 excess error 입니다. 둘 다 묻는 값이 아닙니다.

실제로는 true risk 를 계산할 수 없으므로 두 오차의 값을 구할 수 없습니다. 오차가 어디서 오는지 이해하려고 해 보는 계산입니다.

</section>
