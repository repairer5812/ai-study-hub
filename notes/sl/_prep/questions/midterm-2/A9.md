<section data-q="stem">

At any point on the decision boundary of a logistic regression model with threshold $0.5$, the odds $\dfrac{P(y = 1 \mid \mathbf{x})}{P(y = 0 \mid \mathbf{x})}$ are equal to $0$.

</section>

<section data-q="ko">

임계값이 $0.5$ 인 로지스틱 회귀 모형의 결정 경계 위에 있는 점에서는 odds $\dfrac{P(y = 1 \mid \mathbf{x})}{P(y = 0 \mid \mathbf{x})}$ 가 $0$ 이다.

</section>

<section data-q="answer">

**거짓.** 결정 경계는 두 클래스의 확률이 같아지는 곳입니다. 그곳에서 $P(y = 1 \mid \mathbf{x}) = P(y = 0 \mid \mathbf{x}) = 0.5$ 이므로 odds 는 $\frac{0.5}{0.5} = 1$ 입니다. 0이 되는 것은 odds 에 로그를 취한 log odds 입니다.

같은 경계를 세 눈금으로 적으면 다음과 같습니다.

| 눈금 | 경계 위의 값 |
|---|---|
| 확률 $P(y = 1 \mid \mathbf{x})$ | $0.5$ |
| odds | $1$ |
| log odds $\mathbf{w}^T\mathbf{x} + b$ | $0$ |

odds 는 $e^{\mathbf{w}^T\mathbf{x} + b}$ 이므로 언제나 양수이고 0이 될 수 없습니다. 진술의 odds 를 log odds 로 바꾸거나 $0$ 을 $1$ 로 바꾸면 참이 됩니다.

</section>
