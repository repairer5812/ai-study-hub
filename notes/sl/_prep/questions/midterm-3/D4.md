Consider $f(x)=x^2-2x+e^x$.

(a) [2 points] Find $f'(x)$ and $f''(x)$. Is $f$ strictly convex?

(b) [3 points] Complete A, B and C in this Python implementation:

```python
def gd(x0, step_size, tol=1e-6, max_iter=10000):
    x = x0
    for _ in range(max_iter):
        grad = ____A____
        x_new = ____B____
        delta = ____C____
        x = x_new
        if abs(delta) < tol:
            break
    return x
```

(c) [3 points] Starting from $x_0=0$, compute $x_1$ and $x_2$ with `step_size = 1`. Exact expressions using $e$ are sufficient.

(d) [2 points] Compare $f(x_0)$ and $f(x_1)$. Does strict convexity alone guarantee convergence with this fixed step size? Explain. Two iterations alone are not a proof of long-run divergence.

</section>

<section data-q="ko">

(a) [2점] 미분과 이계도함수를 구하고 엄격한 볼록성을 판단하세요.

(b) [3점] gradient, 갱신값, 변화량을 계산하도록 코드를 채우세요. `np` 는 NumPy입니다.

(c) [3점] $x_0=0$, step size 1에서 두 번 갱신하세요. $e$ 를 포함한 정확한 식으로 답해도 됩니다.

(d) [2점] 첫 갱신에서 함수값이 줄었는지 확인하고, 볼록성만으로 고정 step size의 수렴이 보장되는지 설명하세요. 두 번의 계산만으로 장기적인 발산을 단정하지 마세요.

</section>

<section data-q="answer">

(a) $f'(x)=2x-2+e^x$, $f''(x)=2+e^x>0$ 이므로 엄격히 볼록합니다.

(b) 완성한 세 줄은 다음과 같습니다.

```python
grad = 2*x - 2 + np.exp(x)
x_new = x - step_size * grad
delta = x_new - x
```

변화량은 `x` 를 덮어쓰기 전에 계산해야 합니다. 이 종료 조건은 변화량이 작아졌는지 보는 것이며 그 자체로 최적성의 증명은 아닙니다.

(c) $f'(0)=-1$ 이므로 $x_1=0-(-1)=1$ 입니다. 이어서 $f'(1)=e$ 이므로 $x_2=1-e\approx-1.71828$ 입니다.

(d) $f(x_0)=1$ 이고 $f(x_1)=e-1\approx1.71828$ 이라 첫 갱신에서 오히려 증가했습니다. 볼록성은 적절한 조건에서 최소점의 성질을 설명하지만 아무 step size나 수렴하게 만들지는 않습니다. 곡률에 비해 큰 보폭은 감소를 보장하지 않습니다. 특히 $f''(x)=2+e^x$ 는 실수 전체에서 유계가 아니므로 전역적인 유한 $L$ 을 가정한 step-size 공식을 조건 없이 적용할 수도 없습니다. 여기서 확인한 것은 첫 걸음의 손실 증가와 볼록성만으로는 충분하지 않다는 점입니다.

</section>

<section data-q="rubric">

(a) 2점: $f'$ 에 1점, $f''>0$ 과 볼록성 판정에 1점.

(b) 3점: 코드 A, B, C에 각 1점. C는 `x - x_new` 도 절댓값 종료 조건에서 같은 동작이므로 인정한다. 갱신 부호는 빼기여야 한다.

(c) 3점: $x_1=1$ 에 1점, 둘째 gradient $e$ 에 1점, $x_2=1-e$ 에 1점. 첫 계산이 틀려도 둘째 계산을 일관되게 하면 둘째 과정에 1점까지 준다.

(d) 2점: 함수값 비교로 증가를 확인 1점, 볼록성 외에 보폭 조건이 필요하다는 설명 1점. 전역 $L$ 에 대한 논의는 필수 아니다. 두 번의 계산만으로 발산을 증명했다고 주장하지 않아야 한다.

</section>
