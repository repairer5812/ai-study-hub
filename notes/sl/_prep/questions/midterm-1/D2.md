다항회귀의 닫힌 해를 코드로 옮기는 문제입니다. 입력과 레이블은 $(n,1)$ 배열이고 feature 행렬의 열은 독립이라고 가정합니다.

(a) [6점] 전치, 행렬곱, 역행렬 API를 써서 코드 A, B, C를 채우세요.

(b) [2점] `gram` 과 `w` 의 모양을 쓰세요.

(c) [2점] $K=5$ 일 때 차수를 쓰고, 왜 여전히 선형회귀인지 설명하세요.

(d) [4점] 표는 학습 입력 열 개로 만든 가상 비교 결과입니다. validation MSE로 $K$ 를 고르고, 작은 모형과 큰 모형의 차이 및 학습 오차 0의 한계를 설명하세요. 과제 실행 결과를 그대로 옮긴 표는 아닙니다.

</section>

<section data-q="answer">

(a) 세 빈칸은 차례로 다음과 같습니다.

```python
phi_T = np.transpose(phi)
gram = np.matmul(phi_T, phi)
w = np.matmul(np.matmul(np.linalg.inv(gram), phi_T), y)
```

(b) `gram` 은 $(K,K)$, `w` 는 $(K,1)$ 입니다. $\boldsymbol\Phi$ 의 모양이 $(n,K)$ 이므로 전치가 먼저 와야 $K\times K$ 행렬이 됩니다.

(c) 차수는 $K-1=4$ 입니다. 입력을 거듭제곱으로 바꿔도 추정할 계수들은 곱해져 더해지므로 $\mathbf w$ 에 대해서는 선형입니다.

(d) validation MSE가 4로 가장 작은 $K=5$ 를 고릅니다. $K=2$ 는 학습과 validation 오차가 모두 커서 표현력이 부족한 모형을 의심할 수 있습니다. $K=10$ 은 학습 오차는 0인데 validation 오차는 35로 커서 과적합을 보여 줍니다.

서로 다른 입력 열 개에 항 열 개를 쓰면 정확한 계산에서는 모든 학습점을 지나는 다항식을 만들 수 있습니다. 그러나 관측 잡음까지 맞춘 곡선은 새 데이터에 약할 수 있습니다. 학습 MSE가 가장 작은 모형을 무조건 고르면 안 됩니다. 실제 큰 문제에서는 역행렬을 직접 만드는 대신 선형계 풀이 또는 least-squares solver를 쓰는 방법도 있습니다. 이 코드는 닫힌 해의 행렬 순서를 확인하는 연습입니다.
