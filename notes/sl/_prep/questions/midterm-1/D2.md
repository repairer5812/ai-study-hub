<section data-q="stem">

Consider $f(x)=x^2-2x+e^x$.

(a) [2 points] Find the gradient $f'(x)$.

(b) [3 points] Complete A, B and C in this Python implementation:

```python
def gd(x0, step_size, tol=1e-6, max_iter=10000):
    x = x0
    for _ in range(max_iter):
        grad = ____A____
        x_new = ____B____
        delta = ____C____
        x = x_new
        if abs(delta) < tol:
            break
    return x
```

(c) [5 points] Starting from $x_0=0$, compute $x_1$ and $x_2$ with `step_size = 1`. Exact expressions using $e$ are sufficient.

(d) [4 points] Compare $f(x_0)$ and $f(x_1)$. Does moving opposite to the gradient guarantee a decrease for this step size? Explain the role of step size. Two iterations alone do not prove long-run divergence.

</section>

<section data-q="ko">

(a) [2점] gradient를 구하세요.

(b) [3점] gradient, 갱신값, 변화량을 계산하도록 코드를 채우세요. `np` 는 NumPy입니다.

(c) [5점] $x_0=0$, step size 1에서 두 번 갱신하세요. $e$ 를 포함한 정확한 식으로 답해도 됩니다.

(d) [4점] 첫 갱신에서 함수값이 줄었는지 확인하고, 기울기 반대 방향으로 움직여도 보폭이 크면 손실이 증가할 수 있는지 설명하세요. 두 번의 계산만으로 장기적인 발산을 단정하지 마세요.

</section>

<section data-q="answer">

(a) $f'(x)=2x-2+e^x$ 입니다.

(b) 완성한 세 줄은 다음과 같습니다.

```python
grad = 2*x - 2 + np.exp(x)
x_new = x - step_size * grad
delta = x_new - x
```

변화량은 `x` 를 덮어쓰기 전에 계산해야 합니다. 이 종료 조건은 변화량이 작아졌는지 보는 것이며 그 자체로 최적성의 증명은 아닙니다.

(c) $f'(0)=-1$ 이므로 $x_1=0-(-1)=1$ 입니다. 이어서 $f'(1)=e$ 이므로 $x_2=1-e\approx-1.71828$ 입니다.

(d) $f(x_0)=1$ 이고 $f(x_1)=e-1\approx1.71828$ 이라 첫 갱신에서 증가했습니다. 기울기는 국소 방향을 알려 주지만, 큰 보폭에서 실제 손실 감소까지 보장하지는 않습니다. 적절한 학습률이 필요합니다. 여기서 확인한 것은 첫 걸음의 손실 증가이며 두 번의 계산만으로 장기적인 발산을 증명한 것은 아닙니다.

</section>

<section data-q="rubric">

(a) 2점: $f'(x)=2x-2+e^x$ 에 2점.

(b) 3점: 코드 A, B, C에 각 1점. C는 절댓값 종료 조건에서 반대 순서의 차이도 인정한다.

(c) 5점: $x_1=1$ 에 2점, 둘째 gradient $e$ 에 1점, $x_2=1-e$ 에 2점.

(d) 4점: 두 함수값으로 손실 증가를 확인 2점, 방향과 보폭의 역할을 구분 2점. 수렴 정리나 Hessian의 유도는 요구하지 않는다.

</section>
