<section data-q="stem">

With the number of training samples $n$ held fixed, we replace a linear model with a large neural network, so that the hypothesis class $\mathcal{H}$ becomes much larger. Which change should we expect?

- (a) The approximation error decreases and the estimation error decreases.
- (b) The approximation error decreases and the estimation error increases.
- (c) The approximation error increases and the estimation error decreases.
- (d) The approximation error increases and the estimation error increases.

</section>

<section data-q="ko">

학습 표본 수 $n$ 은 그대로 두고 선형 모형을 큰 신경망으로 바꿔서 가설 집합 $\mathcal{H}$ 가 훨씬 커졌습니다. 어떤 변화를 예상해야 합니까?

- (a) approximation error 는 줄고 estimation error 도 준다.
- (b) approximation error 는 줄고 estimation error 는 는다.
- (c) approximation error 는 늘고 estimation error 는 준다.
- (d) approximation error 는 늘고 estimation error 도 는다.

</section>

<section data-q="answer">

**(b).** 가설 집합이 커지면 표현할 수 있는 함수가 늘어납니다. $\mathcal{H}$ 안의 가장 좋은 함수가 전체에서 가장 좋은 함수에 가까워지므로 approximation error 가 줄어듭니다.

표본 수는 그대로인데 고를 수 있는 함수는 많아졌습니다. 학습 데이터에만 잘 맞는 함수를 고르기 쉬워지므로 estimation error 가 늘어납니다. 두 오차의 합인 excess error 가 줄지 늘지는 정해져 있지 않습니다.

- (a) 둘을 함께 줄이려면 $\mathcal{H}$ 를 키우면서 표본도 늘려야 합니다. 문제에서는 $n$ 이 그대로입니다.
- (c) $\mathcal{H}$ 를 작게 만들 때 일어나는 일입니다.
- (d) $\mathcal{H}$ 가 커지면 그 안에서 가장 좋은 함수의 true risk 는 같거나 낮아집니다. approximation error 가 늘 이유가 없습니다.

</section>
