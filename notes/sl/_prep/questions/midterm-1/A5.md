<section data-q="stem">

When we maximize the likelihood $P(D ; \theta)$, the observed data $D$ is held fixed and the likelihood is regarded as a function of the parameter $\theta$.

</section>

<section data-q="ko">

우도 $P(D ; \theta)$ 를 최대화할 때, 관측한 데이터 $D$ 는 고정하고 우도를 매개변수 $\theta$ 의 함수로 본다.

</section>

<section data-q="answer">

**참.** $P(D ; \theta)$ 는 식의 모양으로는 데이터가 나올 확률입니다. 추정할 때는 보는 방향이 반대입니다. $D$ 는 이미 관측해서 정해진 값입니다. $\theta$ 에 여러 값을 넣어 보며 어느 값에서 이 확률이 큰지를 비교합니다. 가장 크게 만드는 $\theta$ 가 MLE입니다.

동전이라면 앞면과 뒷면이 나온 횟수는 이미 정해져 있습니다. 바꿔 보는 것은 앞면이 나올 확률 $\theta$ 입니다.

</section>
