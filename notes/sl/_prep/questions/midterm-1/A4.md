<section data-q="stem">

If we keep the hypothesis class $\mathcal{H}$ fixed and let the number of training samples $n$ grow to infinity, the approximation error goes to zero.

</section>

<section data-q="ko">

가설 집합 $\mathcal{H}$ 를 그대로 두고 학습 표본 수 $n$ 을 한없이 늘리면 approximation error 는 0으로 간다.

</section>

<section data-q="answer">

**거짓.** approximation error 는 $R^*_{\mathcal{H}} - R^*$ 입니다. $\mathcal{H}$ 안에서 가장 좋은 함수와 모든 함수 가운데 가장 좋은 함수의 true risk 차이입니다. 이 값은 $\mathcal{H}$ 가 어떤 함수를 담고 있느냐로만 정해지고 표본 수와는 관계가 없습니다.

$n$ 을 늘릴 때 0으로 가는 것은 estimation error $R(\hat{h}^*_{\mathcal{H}}) - R^*_{\mathcal{H}}$ 입니다. 표본으로 고른 함수가 $\mathcal{H}$ 안의 가장 좋은 함수에 가까워지기 때문입니다. 진술의 approximation error 를 estimation error 로 바꾸면 참이 됩니다.

approximation error 를 줄이려면 $\mathcal{H}$ 를 키워야 합니다.

</section>
