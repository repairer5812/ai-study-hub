<section data-q="stem">

In regression, the squared loss is more sensitive to outliers than the absolute loss.

</section>

<section data-q="ko">

회귀에서 squared loss 는 absolute loss 보다 이상치(outlier)에 더 민감하다.

</section>

<section data-q="answer">

**참.** squared loss 는 오차의 제곱으로 커지고 absolute loss 는 오차에 비례해 커집니다. 오차가 10이면 squared loss 는 100, absolute loss 는 10입니다. 그래서 멀리 떨어진 점 하나가 squared loss 의 합을 지배하기 쉽습니다.

미분으로 봐도 같습니다. squared loss 의 기울기는 오차에 비례해 커지지만 absolute loss 의 기울기는 오차가 얼마든 크기가 같습니다. 이상치가 섞인 데이터에서는 absolute loss 쪽이 덜 흔들립니다.

</section>
