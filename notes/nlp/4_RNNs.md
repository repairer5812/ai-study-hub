# 4. Sequence Modeling & Recurrent Neural Networks (RNNs)

> **이 챕터 한 줄 요약**
> 언어는 가변 길이 시퀀스다. **FFN 기반 신경 언어 모델**은 희소성은 해결하지만 **고정 문맥 창** 한계가 있다. **RNN**은 같은 가중치를 모든 단어에 재사용해 **임의 길이**를 처리하지만, **기울기 소실·장기 의존성·단방향·노출 편향** 문제가 있고, 이를 **LSTM/양방향/딥 RNN**으로 보완한다.

---

## 1. 시퀀스 모델링 & 신경망 기초

> **시퀀스 모델링 목표**: ① 문맥 의존적 표현 학습 ② 장거리 의존성 포착 ③ 큰 텍스트 단위 간 복잡한 관계 처리.

- 왜 DNN인가? 언어는 **계층적 구조**(글자→단어→구→문장). DNN은 층마다 추상화 수준이 달라 **하위층=저수준 패턴(단어 관계), 상위층=고수준 패턴(문장 의미)**을 학습

### 뉴런 기본 단위 (Perceptron)
- 입력 x, 가중치 w·편향 b → **선형 계산** $z = \mathbf{w}\cdot\mathbf{x}+b$ → **비선형 활성화** $a = f(z)$
- **왜 비선형 활성화?** 선형 연산만 쌓으면 결국 또 다른 선형 연산일 뿐. 복잡한 비선형 관계를 모델링하려면 필요
- 흔한 활성화: **tanh**, **ReLU**

### FFN (Feedforward Network) = MLP
- 각 층 출력이 다음 층으로 전달되는 다층 네트워크. 층마다 가중치 행렬 W·편향 벡터 b
- 2층 FFN: 1층 $h=f(xW_1+b_1)$ → 2층 → 출력(softmax로 확률 분포화)
- **학습 목적함수**: 분류엔 **교차 엔트로피(CE) 손실** = **음의 로그 우도(NLL)**
  $$L = -\sum_k y_k \log \hat{y}_k \quad(\text{one-hot } y \Rightarrow -\log \hat{y}_c)$$
- **학습**: 그래디언트 디센트. 매 스텝 **Forward pass**(손실 계산) + **Backward pass**(연쇄법칙으로 그래디언트, 음의 방향 업데이트). PyTorch 등이 자동 미분 처리

---

## 2. 단순 신경 언어 모델과 한계

> FFN을 언어 모델로 인스턴스화: 단어 임베딩 → 은닉층 → 출력 분포(다음 단어)

- **장점 (희소성 해결)**: 어휘 내 **모든 토큰에 strictly positive 확률**, 의미가 비슷한 단어는 비슷한 확률
- **한계 (핵심)**: **문맥 창이 고정**(N-gram과 동일). 더 많은 단어를 보려면 N을 키워야 하고 → **가중치 W가 커진다.** 연결된 단어 임베딩이 고정 크기여야 함

---

## 3. RNN (Recurrent Neural Network) — 챕터 핵심

> **핵심 아이디어**: **같은 가중치를 모든 입력 단어에 재사용** → **임의 길이(arbitrary length)** 시퀀스 처리. (단순 신경 LM은 단어마다 W의 다른 부분을 곱하지만, RNN은 동일 가중치를 반복 사용)

### 계산
은닉 상태는 ① **이전 스텝 은닉 상태(메모리)** ② **현재 단어 임베딩**으로 계산:
$$\mathbf{h}_t = f(W \mathbf{h}_{t-1} + U \mathbf{x}_t)$$
- W: 순환 연결 가중치, U: 입력 연결 가중치
- 초기 $\mathbf{h}_0$ 설정 후, 각 스텝마다 은닉 상태 계산 → 출력 계산
- **Weight Tying(가중치 묶기)**: 출력 softmax 층에서 **입력 임베딩 행렬을 재사용** → 학습 효율·효과 향상 + 파라미터 감소

### RNN 언어 모델
- 각 스텝의 출력 확률이 **다음 단어를 예측**하도록 학습. $\mathbf{h}^{(t)}$는 $\mathbf{h}^{(t-1)}$과 $\mathbf{x}^{(t)}$의 함수 → 재귀적으로 전체 이전 문맥을 압축
- **텍스트 생성**: [BOS] 입력 → softmax에서 단어 샘플 → 그 단어 임베딩을 다음 입력으로 → [EOS]까지 반복

---

## 4. RNN의 한계 — 시험 단골

| 한계 | 설명 |
|---|---|
| **기울기 소실/폭발** | 역전파 시 그래디언트를 많이 곱함 → 작은 값 다수면 **소실(vanishing)**, 큰 값 다수면 **폭발(exploding)**. 먼 거리 신호가 불안정 |
| **장기 의존성 곤란** | 이론상 임의 길이 기억 가능하나 실제론 어려움. **고정 크기 은닉 상태**에 모든 정보를 압축해야 하고, **최근 입력에 치우쳐** 앞부분을 잊음 |
| **양방향성 부재** | 좌→우로만 처리, 각 스텝은 **과거 정보만** 접근. 예: "The bank is on the river"에서 "bank"는 뒤의 "river"를 봐야 정확히 해소 가능 |
| **노출 편향(Exposure Bias)** | **Teacher forcing**: 학습 시 항상 정답 다음 단어를 입력으로 받음 → 생성 시 자기 예측으로 진행하면 **자기 실수를 교정하는 법을 못 배워** 성능 저하 |

## 5. 고급 RNN

### LSTM (Long Short-Term Memory) — 핵심
> **동기**: RNN 은닉 상태 정보는 지역적이라 먼 정보가 소실. LSTM은 **불필요한 정보는 제거, 미래에 필요한 정보는 추가**.

- 각 스텝 입력: ① 현재 단어 임베딩 ② 이전 은닉 상태 ③ **메모리/셀 상태(cell state)**
- **3개 게이트**:

| 게이트 | 역할 |
|---|---|
| **Forget gate** | 셀 상태에서 **무엇을 버릴지** 결정 |
| **Add/Input gate** | 셀 상태에 **무엇을 새로 저장할지** 결정 |
| **Output gate** | 셀 상태에서 **무엇을 출력할지** 결정 |

- 계산 흐름: forget/input 게이트 + **후보 셀 상태(candidate)** → **셀 상태 갱신**(forget·이전셀 + input·후보) → output 게이트 + 갱신된 셀 상태 → **은닉 상태 갱신**
- → 셀 상태가 **장기 기억의 통로**가 되어 기울기 소실을 완화

### Bidirectional RNN (양방향)
- **순방향·역방향 RNN을 따로 학습**해 두 은닉 상태를 **연결(concatenate)** → 과거+미래 문맥 모두 활용

### Deep RNN (딥)
- RNN 층을 **여러 개 쌓음**. 하위 층 출력이 상위 층 입력, 마지막 층 출력이 최종 출력

## 핵심 용어 정리 (빠른 복습)

| 용어 | 한 줄 정의 |
|---|---|
| **FFN / MLP** | 다층 피드포워드 네트워크 |
| **CE / NLL 손실** | 분류용 교차 엔트로피 = 음의 로그 우도 |
| **Forward/Backward pass** | 손실 계산 / 연쇄법칙 그래디언트 업데이트 |
| **RNN** | 같은 가중치 재사용, 임의 길이 처리 |
| **Weight tying** | 입출력 임베딩 공유로 파라미터 절감 |
| **Vanishing/Exploding gradient** | 그래디언트 곱셈으로 소실/폭발 |
| **Exposure bias / Teacher forcing** | 학습-생성 불일치로 자기 교정 미학습 |
| **LSTM** | forget·input·output 3게이트 + 셀 상태로 장기기억 |
| **Bidirectional / Deep RNN** | 양방향 연결 / 다층 스택 |
