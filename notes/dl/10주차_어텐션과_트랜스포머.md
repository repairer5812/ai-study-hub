## 1. 🧠 Attention의 개념과 도입 배경

### 1.1. 인지심리학적 Attention (슬라이드 직접 인용)
> In psychology, **attention** is a **limited resource** used to **selectively concentrate on some information while ignoring other perceivable information**.

- 슬라이드 Spotlight model: **focus**(중심, 고해상도) / **fringe**(주변) / **margin**(차단).
- 💬 (전사) 교수님 예시: 야구장 이미지를 보면 모든 픽셀이 아니라 선수·심판으로 눈동자(Saccade)가 이동, 관중은 거의 안 봄. 운전 중 신호등엔 즉시 어텐션, 구름엔 X.
- 자연어: "She is eating a **green apple**" — 'green'이 'apple'에 high attention. 한 단어가 같은 문장의 다른 단어에 다르게 "attend".

### 💡 1.2. Seq2Seq의 치명적 한계 (★★★)
- **Seq2Seq**: 입력 시퀀스(source) → 출력 시퀀스(target), 길이 가변 Many-to-Many (번역·Q&A·캡셔닝).
  - **Encoder**: 입력을 단어 단위로 처리해 고정 길이 **Context Vector**(sentence embedding, "thought" vector)로 압축.
  - **Decoder**: Context Vector로 초기화돼 target을 순차 생성. 초기 연구는 **인코더의 마지막 상태만** 디코더 초기값으로 사용.
- **한계 ①: 고정 길이 Context Vector 병목(Bottleneck)** — 문장이 길든 짧든 같은 길이 벡터에 압축 → 긴 문장에서 정보 손실.
  > 슬라이드: fixed-length context vector: **incapable of remembering long sentences (i.e., bottleneck)**.
- **한계 ②: 병렬 계산 불가** — RNN은 이전 타임스텝이 끝나야 다음 계산. 💬 (전사) "RNN의 가장 큰 약점은 병렬 계산이 불가능하다는 것."

## 2. 🎯 Attention Mechanism — Bahdanau NMT

### 2.1. 핵심 아이디어 (슬라이드 직접 인용)
> Broadly interpreted as **a vector of importance weights**... to create **shortcuts between the context vector and the entire source input**. Craft the context vector so that it **"looks at" different parts of the input sequence for each decoder time step.**

- 디코더가 단어를 생성할 때마다 인코더의 **마지막 상태만이 아니라 전체 hidden states를 다시 참조**(shortcut).

### 💡 2.2. 작동 원리 (★★★ 수식)
- 인코더 상태(양방향 RNN concat): $\mathbf{h}_i = \big[\overrightarrow{\mathbf{h}}_i^\top; \overleftarrow{\mathbf{h}}_i^\top\big]^\top$
- **동적 Context Vector** = 인코더 상태의 가중합:
$$\mathbf{c}_t = \sum_{i=1}^{n} \alpha_{t,i}\,\mathbf{h}_i$$
- **Attention Weight** = alignment score에 softmax:
$$\alpha_{t,i} = \text{align}(y_t, x_i) = \text{softmax}\big(\text{score}(\mathbf{s}_{t-1}, \mathbf{h}_i)\big) = \frac{\exp[\text{score}(\mathbf{s}_{t-1}, \mathbf{h}_i)]}{\sum_{j=1}^{n}\exp[\text{score}(\mathbf{s}_{t-1}, \mathbf{h}_j)]}$$
- 디코더 상태: $\mathbf{s}_t = f(\mathbf{s}_{t-1}, y_{t-1}, \mathbf{c}_t)$
- 💡 핵심: Context Vector는 더 이상 고정된 하나가 아니라, **디코더 타임스텝마다 새로 동적 생성**됨. alignment score 행렬은 source-target 단어 상관을 명시적으로 보여줌(설명 가능성).

## 3. 📐 Alignment Score 함수들 (슬라이드 표)

| 이름 | score 함수 | 출처 |
|------|-----------|------|
| Content-base | $\text{score}(\mathbf{s}_t, \mathbf{h}_i) = \cos[\mathbf{s}_t, \mathbf{h}_i]$ | Graves2014 |
| **Additive** | $\mathbf{v}_a^\top \tanh(\mathbf{W}_a[\mathbf{s}_t; \mathbf{h}_i])$ | Bahdanau2015 |
| Location-Base | $\alpha_{t,i} = \text{softmax}(\mathbf{W}_a\mathbf{s}_t)$ (target 위치만 의존) | Luong2015 |
| General | $\mathbf{s}_t^\top \mathbf{W}_a \mathbf{h}_i$ | Luong2015 |
| Dot-Product | $\mathbf{s}_t^\top \mathbf{h}_i$ | Luong2015 |
| **Scaled Dot-Product** | $\dfrac{\mathbf{s}_t^\top \mathbf{h}_i}{\sqrt{n}}$ ($n$=차원) | Vaswani2017 |

## 4. 🔱 Attention의 분류 (★★★ 비교 출제)

### 4.1. Self-Attention (슬라이드 직접 인용)
> Relating different positions of a **single sequence** in order to compute a representation of the same sequence.

- 서로 다른 두 시퀀스가 아니라 **자기 자신 내부** 요소들끼리 관계 계산. (이후 Transformer 핵심)

### 💡 4.2. Soft vs Hard Attention
| 구분 | Soft Attention | Hard Attention |
|------|----------------|----------------|
| 성질 | **Deterministic**(결정론적) | **Stochastic**(확률론적) |
| 방식 | 모든 입력에 가중치 → 가중합 | 가중치 높은 **하나만 샘플링** |
| 미분 | **미분 가능**(smooth, differentiable) | **미분 불가** |
| 비용 | 입력 크면 전부 계산 → 비쌈 | 추론 시 하나만 → 적음 |
| 학습 | 일반 Backpropagation | 강화학습·Monte-Carlo·variance reduction |

- 💬 (전사) 실무·연구는 학습 용이하고 성능 좋은 **Soft Attention을 압도적으로 사용**.

### 4.3. Global vs Local Attention
- **Global**: 입력 시퀀스 전체 대상(Soft와 유사).
- **Local**: Global(비쌈)과 Hard(미분 불가)의 절충 — 먼저 **하나의 정렬 위치 $p_t$를 예측**하고, 그 주변 **윈도우 내에서만** 어텐션(미분 가능 + 계산 절약).

### 4.4. 비전 Attention
- **Image Captioning** (Xu 2015): CNN의 **하위 conv feature map**(공간 정보 보존)에서 단어마다 어느 패치에 집중할지 어텐션. 'dog' 생성 시 강아지 위치에 highlight → **설명 가능성(Explainability)**.
  - soft: $\mathbb{E}_{p(s_t|\mathcal{A})}[\hat{\mathbf{z}}_t] = \sum_{i=1}^{L}\alpha_{t,i}\mathbf{a}_i$ / hard: $\hat{\mathbf{z}}_t = \sum_i s_{t,i}\mathbf{a}_i$ ($s_t \sim$ Multinoulli).
- **VQA**: 이미지(CNN)+질문(RNN) → 질문 단어가 이미지 어디와 연관되는지 어텐션 → 결합 후 **Classification**.

## 5. 🖥️ Neural Turing Machines (NTM) — 미분 가능한 메모리

> Coupling a neural network with **external memory storage**.

- 💬 (전사) 기존 컴퓨터는 정보를 특정 주소에 딱 기록(미분 불가). NTM은 **Attention으로 메모리 전체에 가중치를 두어 '쫙 뿌려서' 읽고/쓰기** → 전 과정이 미분 가능.
- 슬라이드 핵심 문구: **"at every step, read and write everywhere, just to different extents."**
- **Controller**(신경망, 인터페이스) + **Memory** $\mathbf{M}_t \in \mathbb{R}^{N\times M}$, parallel **read/write heads**.
- Read: $\mathbf{r} = \sum_i w_t(i)\mathbf{M}_t(i)$ / Write(erase·add): $\tilde{\mathbf{M}}_t(i)=\mathbf{M}_{t-1}(i)[1-w_t(i)\mathbf{e}_t]$, $\mathbf{M}_t(i)=\tilde{\mathbf{M}}_t(i)+w_t(i)\mathbf{a}_t$.
- Addressing: **Content-based**(cosine: $\mathbf{w}_t^c=\text{softmax}(\beta_t\cos(\mathbf{k}_t,\mathbf{M}_t))$) + **Location-based**(shift) 혼합.
- 💡 의의: Attention을 번역이 아닌 **메모리 Read/Write 연산**에 적용해 폰 노이만 컴퓨터를 미분 가능 신경망으로 구현한 시도.

## 6. 🚀 Transformer — "Attention Is All You Need" (Vaswani 2017)

### 6.1. RNN을 버린 이유 (★★★)
- **Key idea**: Decouple attention from RNNs / Use **self-attention** to make it efficient.
- 버린 이유:
  1. **병렬 처리 불가** (가장 큰 치명타): RNN은 순차 의존 → GPU 병렬 불가.
  2. **Scalability**: 단어 거리 멀어지면 성능 저하.
  3. **Feature Superposition (Polysemanticity)**: 한 뉴런이 여러 무관한 개념을 동시에 처리(entangled) → 설명 가능성 ↓. 💬 (전사) Multi-Head가 이를 완화.
- **Contributions**: Multi-head attention + Transformer architecture. 최초의 **transduction model** relying entirely on self-attention (no RNN/conv).

### 💡 6.2. Q · K · V (★★★ "이 3개가 매우 중요")
RNN 표기($x,h,s,c$)를 버리고 **정보 검색(Information Retrieval)** 의 개념 도입:
| 기호 | 이름 | 의미 |
|------|------|------|
| **Q** | Query | 현재 '찾고자 하는' 기준 정보 |
| **K** | Key | 대상들의 '특징표/이름표' |
| **V** | Value | 대상들의 '실제 내용/값' (보통 K와 같은 출처) |

### 💡 6.3. Scaled Dot-Product Attention (★★★ 핵심 수식)
$$\boxed{\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V}$$
- **내적** $QK^\top$: Q·K 유사도. **스케일링** $\sqrt{d_k}$로 나눔 — 차원 커지면 내적 값이 커져 softmax 기울기 소실(gradient vanishing) 유발 → 방지. **Softmax** → 가중치(합 1). **V 가중합** → 결과.
- 💬 (전사) 스케일링 이유: "값을 곱해서 더하면 계속 퍼지기(커지기) 때문에 차원으로 나눠 조절."

### 6.4. Self vs Cross Attention
- **Self-Attention**: Q, K, V가 **모두 같은 출처**. 문장 내 단어들 간 문맥 관계.
- **Cross-Attention**: Q는 디코더, K·V는 인코더(다른 출처). 생성 단어(Q)가 입력(K,V) 어디에 집중할지.

### 💡 6.5. Multi-Head Attention (★★★)
$$\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1,\dots,\text{head}_h)\,W^O, \quad \text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$
- 예: $h=8$, $d_k=d_v=d_{model}/h=64$ ($d_{model}=512$).
- 💬 (전사) "한 관점만 보지 않고 **여러 관점에서** 본다." 어떤 head는 문법(주어-동사), 어떤 head는 의미(형용사-명사). 차원을 쪼개 계산하므로 **연산량은 single-head와 거의 동일**. Feature Superposition 완화.

## 7. 🏛️ Transformer 아키텍처

### 7.1. Encoder (슬라이드 직접 인용)
> A stack of $N=6$ identical layers. Each layer has a **multi-head self-attention** layer and a position-wise **feed-forward** network. Each sub-layer adopts a **residual connection** and a **layer normalization**. $d_{model}=512$.

- **Add & Norm**: ResNet의 Residual(skip) $\text{LayerNorm}(x + \text{SubLayer}(x))$ + Layer Normalization (학습 안정화).
- **Position-wise FFN**: $\text{FFN}(\mathbf{x}) = \text{ReLU}(\mathbf{x}W_1+b_1)W_2+b_2$ (각 위치에 개별·동일 적용, 보통 4배 확장 후 축소).

### 💡 7.2. Decoder — Masked Self-Attention (★★★ 출제 매우 유력)
- 인코더와 달리 **Masked Multi-Head Self-Attention** + Cross-Attention + FFN.
- **Masking 이유**: Transformer는 시퀀스 전체를 한 번에 입력받지만 생성은 **순차(auto-regressive)**. 학습 시 **미래 단어를 미리 보는 컨닝 방지** → 미래 시점에 $-\infty$ 마스킹해 어텐션 가중치 0.

## 8. 📍 Positional Encoding

> Injecting information about the relative/absolute **position** of tokens... allowing **no recurrence and no convolution**.

- **도입 이유**: RNN을 버리며 순서 정보 상실. 어텐션은 단어 순서를 뒤섞어도 결과 동일(**Permutation Invariant**). 💬 (전사) "단어를 아무렇게나 섞으면 말이 안 되니 순서를 강제로 고려시켜야."
- **방식**: 입력 임베딩에 위치 벡터를 **더하기(Add)** (Concat 아님). 서로 다른 주파수의 sin/cos:
$$\text{PE}_{(pos,2i)} = \sin\!\big(pos/10000^{2i/d_{model}}\big), \quad \text{PE}_{(pos,2i+1)} = \cos\!\big(pos/10000^{2i/d_{model}}\big)$$
- 주기 함수라 **상대 위치**를 쉽게 학습. 💬 (전사 꿀팁) 순서 무관 데이터(Point Cloud, Set)면 **PE만 빼면 Set Transformer**.

## 9. 🤖 LLM 두 갈래: BERT vs GPT (★★★ 비교표 출제 1순위)

| 구분 | **BERT** (Google) | **GPT** (OpenAI) |
|------|------------------|------------------|
| 사용 구조 | Transformer **Encoder**만 | Transformer **Decoder**만 |
| 문맥 | **양방향**(Bidirectional) | **단방향**(Unidirectional) / Auto-Regressive |
| 철학 | 잘 만든 인코더(표현)면 끝단 작은 레이어로 다 해결 | 언어의 본질은 **생성**, 다음 단어 예측을 잘하면 다 깨우침 |
| 학습 | **Masked LM**(약 15% 가림 빈칸 채우기) + **NSP**(다음 문장 예측) | **Next Word Prediction** |
| 목적 | 이해(NLU)·분류·특징 추출 | 생성(NLG)·대화형 AI |

- BERT 특수 토큰: **[CLS]**(문장 전체 의미 압축, 분류용) · **[SEP]**(문장 구분). 활용: 사전학습 BERT + 마지막 Classifier만 **Fine-tuning**.
- 💬 (전사) GPT는 초기엔 BERT에 밀렸으나 **모델 크기를 키우며(Scaling)** ChatGPT로 생성형 AI 절대강자가 됨.

## 10. 🖼️ Vision Transformer (ViT) — 비전으로 확장

- **초기(Image GPT)**: 픽셀을 단어처럼 → 224×224면 픽셀 5만+, 어텐션 연산량 $O(N^2)$ 폭발 → 불가능.
- **ViT 혁신**: 이미지를 **패치(16×16)** 로 자름 → Flatten → 1D 벡터 → **Positional Embedding** + **[CLS] 토큰** → **Transformer Encoder에 그대로 투입** → [CLS] 출력으로 분류.
- 💬 (전사) "패치로 잘랐다. 그리고 트랜스포머에 그냥 집어넣었다. 새로운 게 아무것도 없다." 의의: **CNN의 Inductive Bias를 버리고** 순수 Transformer로 비전 SOTA 달성.
- (상세 패치 임베딩·차원 계산·Inductive Bias·timm 파인튜닝은 **11주차 ViT 실습 노트** 참조.)

## 11. 🗣️ 교수님 코멘트 모음 (전사)

- Attention은 새 발명이 아니라 인간 뇌의 **선택적 집중**을 신경망에 도입한 것.
- RNN의 최대 약점 = **병렬 계산 불가** (시험 단골).
- Q·K·V "이 3개가 매우 중요."
- Multi-Head: "여러 관점에서 본다."
- Masking: 미래 컨닝 방지.
- Positional Encoding은 Concat이 아니라 **Add**.
- Set Transformer = Transformer − Positional Encoding.

## 12. 🎯 10주차 최종 암기 체크리스트

### Attention 기초
- [ ] Attention = 제한된 자원의 **선택적 집중** (Spotlight: focus/fringe/margin)
- [ ] Seq2Seq 한계 ①**고정 Context Vector 병목** ②**병렬 불가** ★★★
- [ ] Bahdanau: 동적 $\mathbf{c}_t=\sum\alpha_{t,i}\mathbf{h}_i$, $\alpha=\text{softmax}(\text{score})$ ★★★
- [ ] Score 함수: Additive(Bahdanau) / Dot / **Scaled Dot**(Vaswani)

### 분류
- [ ] **Self**(단일 시퀀스 내부) / **Soft(미분O·결정)** vs **Hard(미분X·확률·강화학습)** / Global vs Local ★★★
- [ ] 비전: Image Captioning(설명가능성), VQA
- [ ] NTM: "everywhere, different extents", 미분 가능 메모리(content+location addressing)

### Transformer
- [ ] RNN 버린 이유: **병렬 불가** + Scalability + Feature Superposition ★★★
- [ ] **Q·K·V** (Query 찾기 / Key 이름표 / Value 내용) ★★★
- [ ] **Attention(Q,K,V)=softmax(QKᵀ/√d_k)V**, √d_k 스케일링=gradient vanishing 방지 ★★★
- [ ] Self(같은 출처) vs Cross(Q=디코더, K·V=인코더)
- [ ] **MultiHead** = Concat(head)W^O, head=Attention(QW^Q,…), h=8, d_k=64 ★★★
- [ ] Encoder: Multi-Head Self-Attn + Add&Norm(Residual+LayerNorm) + FFN(ReLU)

- [ ] **PE** sin/cos, **Add**(Concat X), Permutation Invariant 해결 ★★★

### LLM·ViT
- [ ] **BERT=Encoder·양방향·MLM+NSP·[CLS]/[SEP]** vs **GPT=Decoder·단방향·Next Word** ★★★
- [ ] **ViT**: 패치→Flatten→PE+[CLS]→Encoder→분류, CNN **Inductive Bias** 버림 ★★★
