# 🌟 12차시 — 그래프 II (Graphs II): 신장트리·최소신장트리(Kruskal·Prim)·최단경로(Dijkstra)·추이적 폐쇄

> **핵심 한 줄 요약**
> 그래프 II는 **가중치 그래프 위의 최적화 4종 세트**. **신장트리**는 모든 정점을 잇고 사이클이 없는 부분 그래프($|E|=n-1$). **최소신장트리(MCST)**는 가중치 합 최소 신장트리로 **Kruskal(간선 기반)·Prim(정점 기반)** 으로 구한다. **최단경로**는 한 출발점에서 모든 정점까지 가중치 합 최소 경로로 **Dijkstra**(distance 갱신=Relaxation)로 구한다. **추이적 폐쇄**는 "i에서 j로 가는 경로가 존재하는가"를 행렬 $A^+$로 표현. **이 차시는 DFS/BFS·Kruskal·Prim·Dijkstra 손풀이가 기말 출제 확정 영역.**

### ⭐ 핵심 출제 ①: DFS/BFS 탐색 과정 (지난 시간 복습이자 출제 확정)
> 🗣️ **교수님 강조**: "기말고사 출제를 명확히 언급한 1) **DFS/BFS를 이용한 탐색 과정**, 2) **Kruskal과 Prim**, 3) **Dijkstra** 거리 벡터 갱신 과정은 반드시 **직접 손으로 그려가며** 연습하세요."
- DFS = "갈 때까지 간다" + 되돌아오기(**스택**), BFS = "인접부터 다 본다"(**큐**).
- 탐색으로 방문한 간선만 남기면 → **신장트리(Spanning Tree)**.

### ⭐ 핵심 출제 ②: Kruskal vs Prim 손풀이 [출제 확정!]
- **Kruskal**: 간선을 가중치 오름차순 정렬 → 작은 것부터, **사이클 생기면 버림** → $n-1$개까지.
- **Prim**: 시작 정점부터 → 현재 트리에 인접한 간선 중 **최소 가중치 정점**을 추가.
> 🗣️ **교수님 팁**: "**가중치가 같을 경우**, 알파벳이 앞서거나 **숫자가 작은 정점**을 연결하는 간선을 우선 선택합니다."

### ⭐ 핵심 출제 ③: Dijkstra 거리 벡터(distance) 갱신 [출제 확정!]
> 🗣️ **교수님 강조 (키포인트)**: "**돌아가더라도(우회하더라도) 가중치의 합이 작으면 우회하는 경로를 선택한다!**"
- 단순 결과만 X → distance 벡터가 **단계별로 어떻게 바뀌고 어떤 정점을 선택하는지** 보여야 정답.

### ⭐ 핵심 출제 ④: 완전 그래프의 신장트리 개수 = $n^{n-2}$
- 정점 $n$개 완전 그래프 → 신장트리 $n^{n-2}$개. (예: $n=4 \to 4^2 = 16$개)

- 건물 간 **컴퓨터 네트워크 통신선**을 사이클 없이 전체 연결.

## 3. 최소신장트리 (Minimum Cost Spanning Tree, MCST) 🌟 [시험 출제 확정!]

![w12 p10](https://repairer5812.github.io/ai-study-hub/assets/images/ds/ds_w12_p10.jpg)

각 간선에 **비용(cost, 거리, 시간)** 이 부여된 그래프에서, $n-1$개의 간선을 택할 때 **가중치 합이 최소**가 되는 신장트리.
→ 대표 알고리즘 **Kruskal**과 **Prim**.

> 🗣️ **[Q&A] 최경찬 학생 질문**: "이 알고리즘(Prim/Kruskal)을 따라간다고 해서 최소신장트리를 **반드시 구한다는 게 보장**되나요? 더 짧은 우회로가 있을 수도 있지 않나요?"
> 🗣️ **교수님 답변**: "두 알고리즘 모두 사이클을 방지하면서 항상 '**현재 상황의 최소 가중치(Local Minimum)**'만 선택해 연결하므로, 궁극적으로 전체 합이 최소인 '**최소신장트리(Global Minimum)**'를 도출함이 **수학적으로 보장**됩니다." (그리디 최적성)

### 3.1 Kruskal's Algorithm — 간선(Edge) 기반 🌟

![w12 p11](https://repairer5812.github.io/ai-study-hub/assets/images/ds/ds_w12_p11.jpg)

**동작 원리**
1. 모든 간선을 가중치 **오름차순 정렬**.
2. 가장 작은 간선부터 순서대로 선택.
3. **사이클이 생기는 간선은 버린다(discard)**.
4. 선택된 간선이 $n-1$개가 될 때까지 반복.

```c
T = {};   /* T에 구해진 에지를 더한다 */
while (T contains less than n-1 edges && E is not empty) {
    choose a least cost edge (v,w) from E;   /* 가장 작은 가중치 간선 */
    delete (v,w) from E;
    if ((v,w) does not create a cycle in T)
        add(v,w) to T;       /* 사이클 안 생기면 추가 */
    else
        discard(v,w);        /* 사이클 생기면 버림 */
}
if (T contains fewer than n-1 edges)
    printf("no spanning tree\n");
```

> 🗣️ **교수님 팁**: "**가중치가 같으면** 알파벳이 앞서거나 **숫자가 작은 정점**을 연결하는 간선을 우선 선택하세요." (동률 처리 디테일 → 답안 일관성)

### 3.2 Prim's Algorithm — 정점(Vertex) 기반 🌟

![w12 p15](https://repairer5812.github.io/ai-study-hub/assets/images/ds/ds_w12_p15.jpg)

**동작 원리**
1. 시작 정점을 **Tree Vertex 집합(TV)** 에 넣음.
2. TV에 인접한 간선 중 **가중치가 가장 작은 간선**의 정점을 TV에 추가.
3. 이미 TV에 있는 정점을 다시 잇지 않도록(사이클 방지) 주의.
4. 간선이 $n-1$개가 될 때까지 반복.

```c
T = {};         /* 초기에 빈 노드의 그래프 */
TV = {0};       /* 노드번호 0번에서 시작 */
while (T contains fewer than n-1 edges) {
    let (u,v) be a least cost edge
        such that u ∈ TV and v ∉ TV;   /* 한쪽은 트리 안, 한쪽은 밖 */
    if (there is no such edge) break;
    add v to TV;
    add (u,v) to T;
}
if (T contains fewer than n-1 edges)
    printf("no spanning tree\n");
```

#### Prim 수행 예 (슬라이드, 0번 시작)
TV 변화: {0} → {0,5} → {0,5,4} → {0,5,4,3} → {0,5,4,3,2} → {0,5,4,3,2,1} → {0,5,4,3,2,1,6}
(포함 간선: (0,5)10 → (5,4)25 → (4,3)22 → (3,2)12 → (2,1)16 → (1,6)14)

## 4. 최단경로 (Shortest Path) 🌟 [시험 출제 확정!]

![w12 p19](https://repairer5812.github.io/ai-study-hub/assets/images/ds/ds_w12_p19.jpg)

### 4.1 정의
**하나의 출발 정점**에서 다른 모든 정점까지 이르는 경로 중 **간선 가중치 합이 최소**인 경로. 가중치 = 시간·비용·거리.
- 서울 지하철: 종로1가→강남까지 **가장 빠른 시간/짧은 거리/적은 역 수**.
- 역 수만 따지면 모든 간선 가중치를 1로 두면 됨.
- **경로의 길이 = 경로상 간선 가중치들의 합**.

> 슬라이드 예: $V_0$에서 → $V_2$(10) → $V_2 V_3$(25) → $V_2 V_3 V_1$(45) → $V_4$(45). 즉 $V_0 \to V_1$을 **바로(50) 가지 않고 우회(45)** 하는 게 더 짧다.

### 4.2 핵심 원리 (Dijkstra)

![w12 p22](https://repairer5812.github.io/ai-study-hub/assets/images/ds/ds_w12_p22.jpg)

> 🗣️ **교수님 강조 (키포인트)**: "**돌아가더라도 가중치의 합이 작으면 우회하는 경로를 선택한다!**"

- **distance[w]**: 출발점 $x$에서 정점 $w$까지 현재까지 알려진 **최단 거리**.
- **집합 S**: 이미 최단경로가 **확정된** 정점들의 집합.
- 정점 선택: $u \notin S$ 중 **distance[u]가 최소**인 정점을 골라 S에 넣음.
- **갱신(Relaxation)**: 새 정점 $u$를 거쳐 $w$로 가는 길이 더 짧으면 갱신.

$$ \text{distance}[w] = \min\{\ \text{distance}[w],\ \ \text{distance}[u] + \text{cost}[u][w]\ \} $$

> 💡 두 후보: ① S만 거쳐가는 거리(이미 계산됨) = distance[w] ② $u$를 경유 = distance[u] + length($u,w$). 더 작은 값 선택.

### 4.4 Dijkstra 코드

![w12 p24](https://repairer5812.github.io/ai-study-hub/assets/images/ds/ds_w12_p24.jpg)

```c
void shortestpath(int v, int cost[][MAX_VERTICES],
                  int distance[], int n, short int found[]) {
    int i, u, w;
    for (i = 0; i < n; i++) {        /* 초기화 */
        found[i] = FALSE;
        distance[i] = cost[v][i];
    }
    found[v] = TRUE;
    distance[v] = 0;
    for (i = 0; i < n - 1; i++) {
        u = choose(distance, n, found);   /* 미방문 중 최소 distance */
        found[u] = TRUE;
        for (w = 0; w < n; w++)
            if (!found[w])
                if (distance[u] + cost[u][w] < distance[w])
                    distance[w] = distance[u] + cost[u][w];  /* Relaxation */
    }
}
```

```c
int choose(int distance[], int n, int found[]) {
    int i, min = INT_MAX, minpos = -1;
    for (i = 0; i < n; i++)
        if (distance[i] < min && !found[i]) {
            min = distance[i];
            minpos = i;
        }
    return minpos;   /* 미방문 정점 중 최소 distance의 위치 */
}
```

## 5. 추이적 폐쇄 (Transitive Closure)

![w12 p36](https://repairer5812.github.io/ai-study-hub/assets/images/ds/ds_w12_p36.jpg)

### 5.1 추이적 관계와 도달 가능성
- **추이적 관계(Transitive)**: $a R b$ 이고 $b R c$ 이면 $a R c$. ($A \to B,\ B \to C \Rightarrow A \to C$)
- "크다·크거나 같다·같다" 관계는 추이적.
- **도달 가능성(Reachability)**: 그래프에서 어떤 정점 $i$에서 정점 $j$로 **경로가 존재하는가**.

> 💡 무방향 그래프는 모두 연결돼 있으면 어디서든 모두 도달 가능. **방향 그래프**는 화살표 방향 때문에 도달 불가 정점이 생길 수 있다 (예: $C \to B \to D$는 가능하나 $D$에서 $A,B$로는 역방향이라 불가).

### 5.2 추이적 폐쇄 행렬 $A^+$
- **정의**: 정점 $i$에서 $j$로 가는 경로(길이 $> 0$)가 **하나라도 있으면 $A^+[i][j]=1$, 없으면 0**.
- 인접 행렬 $A$로부터 $A^+$를 구하는 방법: **행렬을 곱해서** 구한다 (경로 길이 누적).

```c
// Floyd-Warshall로 추이적 폐쇄 계산
void transitiveClosure(int graph[][MAX_VERTICES], int numVertices) {
    int closure[MAX_VERTICES][MAX_VERTICES];
    for (int i = 0; i < numVertices; ++i)
        for (int j = 0; j < numVertices; ++j)
            closure[i][j] = graph[i][j];           // 초기 = 인접 행렬

    for (int k = 0; k < numVertices; ++k)          // 경유 정점 k
        for (int i = 0; i < numVertices; ++i)
            for (int j = 0; j < numVertices; ++j)
                closure[i][j] = closure[i][j] || (closure[i][k] && closure[k][j]);
    // i→k 경로 && k→j 경로 있으면 i→j 도달 가능
}
```

> 💡 **출제 포인트**: 슬라이드 예에서 인접 행렬 $A$($a\to b,\ b\to d,\ d\to a,\ d\to c$)의 추이적 폐쇄 $T$는 $c$행만 전부 0(나가는 간선 없어 어디도 도달 못 함), 나머지 행은 전부 1. **나가는 간선이 없는 정점은 도달 가능 정점이 없다.**

### 5.3 활용
- **분산 시스템·병렬 시스템**의 전이 네트워크 **도달 가능성 분석**.
- **컴파일러 구성**에서 **파싱 오토마타** 구성 시.

- [ ] 비트리 에지 추가 → 반드시 사이클 발생
- [ ] DFS/BFS spanning tree, 신장트리는 여러 개
- [ ] **완전 그래프 신장트리 개수 = $n^{n-2}$** ($n=4 \to 16$)

- [ ] **Prim = 정점 기반**: 시작 정점에서 TV 키우기 → TV 밖 최소 간선 정점 추가

- [ ] 그리디 Local Min 선택 → Global Min(최소신장트리) **수학적 보장**

### 최단경로 (Dijkstra) 🌟 [출제 확정]
- [ ] 출발점 1개 → 모든 정점 최단거리(distance) 동시 계산
- [ ] 핵심: **우회해도 합이 작으면 우회 선택**
- [ ] choose = 미방문 중 distance 최소 정점 선택 → S에 추가
- [ ] Relaxation: distance[w] = min(distance[w], distance[u]+cost[u][w])
- [ ] 인접 X = 무한대(1000), incoming 없는 정점은 끝까지 ∞
- [ ] 답안은 **단계별 distance 벡터 변화 + 선택 정점** 보여주기

### 추이적 폐쇄
- [ ] 추이적: $a\to b,\ b\to c \Rightarrow a\to c$ = 도달 가능성
- [ ] $A^+[i][j]=1$ ⇔ $i$에서 $j$로 경로(길이>0) 존재
- [ ] 인접 행렬 곱(또는 Floyd-Warshall)으로 계산
- [ ] 나가는 간선 없는 정점은 도달 정점 없음, 활용=도달성 분석·파싱 오토마타
