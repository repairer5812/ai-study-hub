# 🌟 11차시 — 그래프 I (Graphs I): 개념·표현·탐색(DFS/BFS)

> **핵심 한 줄 요약**
> 그래프는 **m:n 관계**를 표현하는 비선형 자료구조 $G = (V, E)$. **무방향( )/방향< >**, **완전 그래프 간선 수**(무방향 $n(n-1)/2$, 방향 $n(n-1)$), **인접(adjacent)·부속(incident)·차수(degree)·경로·사이클·강연결** 용어가 핵심. **표현**은 인접 행렬($O(N^2)$, 무방향이면 대칭)/인접 리스트. **탐색**은 **DFS(스택, 트리 전위 탐색에 대응)**·**BFS(큐, 트리 레벨 탐색에 대응)**. 둘 다 지나간 간선만 남기면 **신장 트리**가 된다. **이 차시는 기말고사 핵심 출제 영역(adjacent 연산·탐색·오일러 조건).**

---

## 🎯 11차시 핵심 출제 포인트 프리뷰 🌟

### ⭐ 핵심 출제 ①: 트리 탐색은 기말고사 1번 문제 (그래프 탐색과 짝지어 기억)
> 🗣️ **교수님**: "별표 친 거는 약속된 기말고사 출제 문제입니다. **트리에서의 탐색(전위·중위·후위·레벨)은 기말고사 1번 문제로 출제 확정!**"
- 트리 전위 탐색 ↔ 그래프 **DFS**, 트리 레벨 탐색 ↔ 그래프 **BFS**로 대응시켜 외운다.

### ⭐ 핵심 출제 ②: adjacent(v) 연산 — 출제 확정
> 🗣️ **교수님 강조**: "**adjacent(v) 연산은 자료구조 사용 설명서(ADT)에 나오며 기말고사에 출제됩니다.** 탐색할 때 '다음에 어디로 갈지' 결정하는 가장 필수적인 연산이에요."
- adjacent(v): 정점 $v$에 인접한 정점들의 **리스트를 반환**.

### ⭐ 핵심 출제 ③: 신장 트리·최소 신장 트리·최단 경로 (메모에 별표)
> 🗣️ **교수님**: "신장 트리, 최소 신장 트리, 최단 경로에 **별표를 치세요.** 약속된 기말고사 출제 문제입니다." (자세한 알고리즘은 12차시)

### ⭐ 핵심 출제 ④: 오일러 경로 조건 + 완전 그래프 간선 수
- 오일러 경로 존재 조건: **모든 정점 연결 + 차수 홀수인 정점이 2개 이하**.
- 완전 그래프 간선 수: 무방향 $n(n-1)/2$, 방향 $n(n-1)$.

### ⭐ 핵심 출제 ⑤: DFS=스택, BFS=큐 / 작은 번호부터 방문
> 🗣️ **교수님(BFS 라이브 트레이싱 중)**: "어? 3, 6 아니에요? 잠깐만요. **큐에는 무조건 작은 숫자를 먼저 넣게 되거든요...** 어! 50분이다. 이건 다음 시간에 다시 하겠습니다."
> 💡 **출제 포인트(함정)**: BFS 큐 삽입 순서는 **반드시 작은 번호부터**. 백지에 큐를 그려가며 트레이싱할 것.

### 📝 시험 형식
- **100% 객관식(선다형)** (전 차시 동일)
- 이번 차시 진도는 **개념·표현·탐색까지**. 신장트리·최단경로·추이적 폐쇄는 12차시.

### 1.2 그래프의 정의 (추상화)
- 그래프 = **정점(Vertex/Node)** 과 **간선(Edge/Link)** 의 집합.
- **정점**: 데이터·개체·소자. **간선**: 정점 간의 연결·관계.
- 간선에는 **방향**과 **가중치(weight)** 를 줄 수 있어 복잡한 관계 표현 가능.
  - 가중치 의미: 시간·속도·거리·비용·신뢰도·친밀도 등.

> 🗣️ **교수님 농담**: "제가 어떤 분이랑 친해지려면 누구를 통해서 가야 빨리 친해질 수 있는지, 이런 **친밀도나 관계도 그래프로 해결**할 수 있습니다."

> 🗣️ **교수님 농담(트리=특수 그래프)**: "트리에서는 부모-자식 간에 **가중치를 주지 않아요.** 부모님은 모든 자식을 똑같은 마음으로 사랑하시거든요. 가중치가 있다면 편애하는 거겠죠?"

> 💡 **출제 포인트**: **트리는 사이클이 없는 연결 그래프**(루트 1개). 즉 트리 ⊂ 그래프.

## 3. 그래프의 시초: 오일러의 쾨니히스베르크 다리 문제 🌟

![w11 p05](https://repairer5812.github.io/ai-study-hub/assets/images/ds/ds_w11_p05.jpg)

- **1800년대(1741년) 오일러(Euler)** 가 창안 → 그래프 이론의 출발점.
- **문제**: 쾨니히스베르크의 프레겔 강이 가른 A·B·C·D 네 지역을 잇는 **7개의 다리**를, **모든 다리를 딱 한 번씩만 건너서** 처음 출발지로 돌아올 수 있는가?
- **추상화**: 복잡한 지형(나무·집)을 버리고 **땅 = 정점**, **다리 = 간선**으로 단순화.

### 💡 오일러 정리 (오일러 경로 존재 조건) 🌟
> 1. **모든 정점이 연결**되어 있어야 한다.
> 2. **차수가 홀수인 정점이 2개 이하**여야 한다.

- **결론**: 쾨니히스베르크 네 정점의 차수 = **5, 3, 3, 3** → 모두 홀수(홀수 정점 4개) → **오일러 경로 존재하지 않음** (해결 불가)을 수학적으로 증명.

## 4. 그래프의 수학적 정의와 종류

![w11 p06](https://repairer5812.github.io/ai-study-hub/assets/images/ds/ds_w11_p06.jpg)

- $G = (V, E)$
  - $V(G)$: 정점 집합(set of vertices)
  - $E(G)$: 간선 집합(set of edges), $V \times V$의 **부분집합**

## 6. 그래프 핵심 용어 사전 🌟 (객관식·변별 빈출)

> 🗣️ **교수님 강조**: 트리와 비교하며 세세하게 설명한 용어들. 객관식·단답형으로 헷갈리게 출제될 수 있음.

### 6.1 인접 / 부속 🌟
![w11 p10](https://repairer5812.github.io/ai-study-hub/assets/images/ds/ds_w11_p10.jpg)

<table header-row="true">
<tr>
<td>용어</td>
<td>관점</td>
<td>정의</td>
</tr>
<tr>
<td>**인접 (Adjacent)**</td>
<td>정점 ↔ 정점</td>
<td>간선 $(a,b)$가 있을 때 정점 $a$는 정점 $b$에 **인접**</td>

### 6.2 부분 그래프 (Subgraph)
- $V(G') \subseteq V(G)$ 이고 $E(G') \subseteq E(G)$.
- **주의**: 그래프는 트리와 달리 모든 정점이 연결될 필요 없음. 정점 하나만 덜렁 있거나 간선이 끊겨도 부분 그래프.

### 6.5 차수(Degree) 🌟
- 정점에 **부속된 간선의 수**.
- **방향 그래프**에서는 구분:
  - **진입 차수 (In-degree)**: 정점으로 **들어오는** 간선 수
  - **진출 차수 (Out-degree)**: 정점에서 **나가는** 간선 수

## 7. 그래프의 표현 (메모리 구조) 🌟

### 7.1 인접 행렬 (Adjacency Matrix) 🌟
![w11 p17](https://repairer5812.github.io/ai-study-hub/assets/images/ds/ds_w11_p17.jpg)

- 정점 수 $N$일 때 $N \times N$ **2차원 배열**.
- `adj_mat[i][j]` = $v_i, v_j$가 인접하면 **1(또는 가중치)**, 아니면 **0**.
- **공간 복잡도**: $S(n) = O(N^2)$ → 정점 많으면 메모리 낭비.
- **무방향 그래프**: 대각선 기준 **대칭(Symmetric)**.
- Self-loop 없으면 대각선은 모두 0.

> 💡 **출제 포인트**: 인접 행렬 공간 복잡도 = $O(N^2)$, **무방향이면 대칭**. 행렬을 보고 그래프를 복원하거나 차수(행/열의 1 개수)를 세는 문제 대비.

### 7.2 인접 리스트 (Adjacency List) 🌟
![w11 p18](https://repairer5812.github.io/ai-study-hub/assets/images/ds/ds_w11_p18.jpg)

## 9. 그래프의 탐색 (Traversal) 🌟 [핵심 출제]

![w11 p22](https://repairer5812.github.io/ai-study-hub/assets/images/ds/ds_w11_p22.jpg)

- **탐색(Traversal)**: 모든 정점을 **중복 없이 딱 한 번씩** 방문.
- 그래프 연산 중 **가장 중요**. 방문 순서에 따라 DFS / BFS.
- **공통 규칙**: 갈 수 있는 인접 정점이 여러 개면 **번호가 작은 것(알파벳 빠른 것)부터** 방문.
- **방문 체크 배열**: `visited[MAX_VERTICES]` — 사이클로 인한 무한 루프 방지. 초기값 FALSE(0), 방문 시 TRUE(1).

### 9.1 깊이 우선 탐색 (DFS) 🌟
![w11 p25](https://repairer5812.github.io/ai-study-hub/assets/images/ds/ds_w11_p25.jpg)

> 🗣️ **교수님 비유**: "DFS는 **자동차로 여행할 때 직진만 하는 것**입니다. 방문지가 있으면 무조건 가고, 길이 막히거나 이미 방문한 곳이면 **후진(Backward)** 해서 갈림길로 돌아간 뒤 안 가본 길로 다시 깊게 파고듭니다."

- **자료구조: 스택** (후진해야 하므로 LIFO). 방문 노드를 스택에 push, 막히면 pop.
- **단계**: ① 한 노드 택함 → ② 방문·작업 후 인접 노드로 이동(현재 노드 스택 저장), 막히면 ③ → ③ 스택에서 pop해 이전 노드로 돌아가 ②반복.
- **시간 복잡도**: $O(e)$ ($e$ = 간선 수).

```c
/* 깊이 우선 탐색 — 정점 v에서 시작 */
void dfs(int v) {
    node_ptr w;
    visited[v] = TRUE;          /* 1. 방문지 표시 */
    printf("%d ", v);
    for (w = graph[v]; w; w = w->link)  /* 2. 인접 리스트 탐색 */
        if (!visited[w->vertex])
            dfs(w->vertex);     /* 미방문 정점으로 재귀 */
}
```

> 🗣️ **교수님 라이브 트레이싱(성공)**: 정점 10개 그래프에서 경로 `0 → 1 →(후진)→ 2 → 3 → 5 → 9 →(후진)→ 7 → 6 →(후진)→ 8 → 4`. "방문하며 거친 간선이 **9개($n-1$개)**? 이건 **트리가 된 거예요. 즉 DFS/BFS로 신장 트리(Spanning Tree)를 구할 수 있다**는 뜻입니다!"

### 9.2 너비 우선 탐색 (BFS) 🌟
![w11 p28](https://repairer5812.github.io/ai-study-hub/assets/images/ds/ds_w11_p28.jpg)

> 🗣️ **교수님 비유**: "BFS는 **가까운 곳부터 모두 방문**합니다. 거리 1인 정점을 다 방문하고, 그다음 거리 2인 정점을 물결 퍼지듯 방문하죠."

- **자료구조: 큐** (먼저 발견한 가까운 정점을 먼저 방문 → FIFO). 방문할 정점을 enqueue, 방문 시 dequeue.
- **단계**: ① 한 노드 택해 방문·enqueue → ② 큐 front를 dequeue → 그 정점의 미방문 인접 정점을 모두 enqueue → 큐가 빌 때까지 반복.

```c
/* 너비 우선 탐색 — 정점 v에서 시작 */
void bfs(int v) {
    node_ptr w; queue_ptr front, rear;
    front = rear = NULL;        /* 큐 초기화 */
    printf("%d ", v);
    visited[v] = TRUE;          /* 1. 방문지 기록 */
    insert(&front, &rear, v);
    while (front) {             /* 2. 방문지 있는 동안 반복 */
        v = delete(&front);
        for (w = graph[v]; w; w = w->link)
            if (!visited[w->vertex]) {
                printf("%d ", w->vertex);
                insert(&front, &rear, w->vertex);
                visited[w->vertex] = TRUE;
            }
    }
}
```

> 🗣️ **교수님 라이브 트레이싱(해프닝)**: "0번부터 시작해 인접한 1, 2, 4, 6을 순서대로 큐에 넣고... **어? 3, 6 아니에요? 잠깐만요. 큐에는 무조건 작은 숫자를 먼저 넣게 되거든요.** ...어! 50분이다. 이건 다음 시간에 다시 하겠습니다."
> 💡 **출제 포인트(함정)**: BFS는 인접 정점을 큐에 넣을 때 **반드시 작은 번호부터**. 순서가 꼬이기 쉬우니 백지에 큐 상태를 그려가며 트레이싱.

### 9.3 코드로 보는 인접 리스트 생성 + 탐색 (슬라이드 32~37)
![w11 p26](https://repairer5812.github.io/ai-study-hub/assets/images/ds/ds_w11_p26.jpg)

- 인접 **행렬**을 읽어 인접 **리스트**로 변환 후(`create()`) DFS/BFS 수행.

## 10. 연결 요소의 계산 (Connected Components)

![w11 p30](https://repairer5812.github.io/ai-study-hub/assets/images/ds/ds_w11_p30.jpg)

- 그래프가 여러 덩어리로 나뉠 수 있음. **임의 정점에서 DFS/BFS 한 번** 수행 → 그 정점과 **연결된 하나의 덩어리** 전부 방문.
- 방문 안 한 남은 정점에서 다시 탐색 시작 → 다음 연결 요소 발견.

```c
void connected(void) {
    int i;
    for (i = 0; i < n; i++)
        if (!visited[i]) {
            dfs(i);
            printf("\n");   /* 연결 요소 하나 출력 끝 */
        }
}
```

- **예**: $G_4$에 적용하면 결과가 **2줄** → 연결 요소 **2개**(`0 1 2 3` / `4 5 6 7`).

> 💡 **출제 포인트**: `connected()`가 출력하는 줄 수 = **연결 요소 개수**. for문 안에서 `dfs(i)`가 호출된 횟수와 같다.

## 🎯 11차시 최종 암기 체크리스트

### 그래프 기본 개념
- [ ] 관계 분류: 1:1 리스트(선형) / 1:n 트리 / **m:n 그래프**(비선형)
- [ ] $G = (V, E)$, 간선은 $V \times V$의 부분집합
- [ ] 트리 = 사이클 없는 연결 그래프(루트 1개), 트리 ⊂ 그래프
- [ ] 가중치 의미: 시간·거리·비용·신뢰도·친밀도

### 오일러 문제 🌟
- [ ] 추상화: 땅=정점, 다리=간선
- [ ] 오일러 경로 조건: **모든 정점 연결 + 차수 홀수 정점 ≤ 2개**
- [ ] 쾨니히스베르크: 차수 5,3,3,3(홀수 4개) → 경로 없음

### 그래프 종류·표기
- [ ] 무방향 = 괄호 $(v_i,v_j)$, $(v_i,v_j)=(v_j,v_i)$
- [ ] 방향 = 꺾쇠 $\langle v_i,v_j\rangle$, $\langle v_i,v_j\rangle \ne \langle v_j,v_i\rangle$
- [ ] Simple / Multigraph / Self-loop 구분
- [ ] **완전 그래프 간선 수**: 무방향 $n(n-1)/2$, 방향 $n(n-1)$ (정점 4개→6개)

### 용어 사전 🌟
- [ ] **인접(adjacent)=정점끼리 / 부속(incident)=간선이 정점에**
- [ ] 부분 그래프(연결 불필요), 경로, 경로 길이 = 간선 수
- [ ] 단순 경로 / 사이클(처음=끝)
- [ ] 연결됨 / 연결된 부분(component) / **강연결(SCC, 방향 그래프 상호 도달)**
- [ ] 차수 = 부속 간선 수, 방향이면 in-degree / out-degree

### 표현 방법 🌟
- [ ] 인접 행렬: $O(N^2)$, 무방향이면 **대칭**, adj_mat[i][j]=1 or 0
- [ ] 인접 리스트: 정점별 연결 리스트 배열, 희소 그래프에 효율적

### ADT 🌟
- [ ] **adjacent(v) = 인접 정점 리스트 반환 (출제 확정)**
- [ ] create / init / insert·delete (vertex·edge) / is_empty / destroy

### 탐색 DFS·BFS 🌟 (핵심 출제)
- [ ] 탐색 = 모든 정점 중복 없이 한 번씩, visited 배열로 무한 루프 방지
- [ ] 공통 규칙: 인접 정점 여러 개면 **작은 번호부터**
- [ ] **DFS = 스택 = 트리 전위 / BFS = 큐 = 트리 레벨**
- [ ] DFS 시간 복잡도 $O(e)$
- [ ] BFS 큐 삽입 순서 함정: 작은 번호부터(트레이싱 필수)
- [ ] DFS/BFS로 지나간 간선만 남기면 **신장 트리**(간선 $n-1$개)

### 연결 요소
- [ ] `connected()`의 dfs 호출 횟수 = 연결 요소 개수
- [ ] $G_4$ → 2개 (0 1 2 3 / 4 5 6 7)

- [ ] 신장 트리 / 최소 신장 트리(MST) / 최단 경로 / 추이적 폐쇄(Reachability)
