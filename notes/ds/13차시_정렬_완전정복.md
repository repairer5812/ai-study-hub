# 🌟 13차시 — 정렬(Sorting) 완전 정복 [기말]

> **범위**: 정렬의 개념·분류·성능 평가 → 기본 정렬(선택·버블·삽입) → 효율 정렬(퀵·힙) → 기타 정렬(셸·머지·기수). 본 차시는 그래프(12차시) 핵심을 한 번 복습한 뒤 정렬로 들어갔다.
>
> 💡 **출제 1순위**: Swap 시 이동 3번 · 힙 = 완전 이진 트리(출제 예고) · 퀵 정렬 최악 O(N²) 조건 · 기수 정렬 = 비교 없는 유일 정렬.

---

## 0. 🔗 그래프 핵심 보강 (12차시 연계)

본 차시 도입에서 12차시 그래프를 빠르게 복습했다. 정렬과 별개로 기말 출제 영역이므로 핵심만 정리한다(상세는 12차시 노트).

### 최소 비용 신장 트리(MCST)
- 모든 정점이 연결되고 사이클이 없는 간선 **n−1개** 트리 중, 간선 가중치 합이 **최소**인 트리.
- **프림(Prim, 정점 중심)**: 시작 정점에서 출발해 트리에 인접한 간선 중 최소 가중치 간선의 정점을 하나씩 추가.
- **크루스칼(Kruskal, 간선 중심)**: 간선을 가중치 오름차순 **정렬**한 뒤 작은 것부터 추가. 💡 **사이클이 생기는 간선은 배제**.
- 🗣️ **시작점 선정 팁(Q&A)**: 크루스칼처럼 간선 중심이라 루트가 애매하면, **첫 최소 간선에 연결된 두 정점 중 더 작은 값(또는 알파벳 앞)** 을 시작점으로 본다.

### 최단 경로 — 다익스트라(Dijkstra)
- 하나의 시작 정점에서 **다른 모든 정점까지의 최단 거리(Distance Vector)** 를 구한다.
- **핵심 원리(Relaxation)**: 돌아가더라도 **경유 경로의 가중치 합이 더 작으면 그 경로로 갱신(Update)** 한다.
- 🗣️ **경유 라우팅 비유**: 먼 지인에게 직접 물으면 10초가 걸리지만, 친한 지인을 거쳐 물으면 1초+1초=2초로 더 빠를 수 있다 → 직접 간선보다 경유 합이 작으면 경유로 바꾼다.
- **정점 선택 = 최단 거리 확정**: 한 번 선택된 정점은 거리가 확정되어 더 이상 수정하지 않는다. 매 단계 미확정 정점 중 거리 최소 정점을 선택하고, 그 정점을 경유한 이웃들의 거리를 갱신한다.
- ⚠️ **함정**: 정점이 **선택된 순서**(예: 0 → 2 → 1 → 5 → 3 → 4 → 6)는 **거리가 확정되어 집합에 추가된 순서일 뿐, 최단 경로의 경유 순서가 아니다.**

### 추이적 폐쇄(Transitive Closure)
- A→B 도달, B→C 도달이면 **A→C도 도달** 가능(도달 가능성, Reachability).
- 방향 그래프에서 나가는 간선이 없는 정점은 어디로도 못 갈 수 있다.
- 💡 **계산법**: 정점이 N개면 **인접 행렬을 N−1번 곱하면** 추이적 폐쇄 행렬을 얻는다. (사이클 없는 최대 경로 길이가 n−1개 간선이기 때문. 예: 정점 4개 → 3번 곱)

## 1. 정렬의 개념과 성능 평가

### 1-1. 개념·분류
- **정의**: 데이터를 크기 순(오름/내림차순)으로 나열하는 것. **목적은 검색을 빠르게 하기 위함**.
- 🗣️ **비유**: 도서관 서지정보가 정렬돼 있지 않으면 책 찾는 데 막대한 시간이 든다. 학생·교과목 정보도 정렬돼 있어야 빠른 처리가 가능하다.
- **내부 정렬(Internal Sort)**: 데이터가 주기억장치(RAM) 용량보다 작을 때. 선택·버블·삽입·퀵·힙 등.
- **외부 정렬(External Sort)**: 데이터가 너무 커서 디스크 등 외부 기억장치로 분할 정렬 후 합침. 머지 정렬이 대표.

### 1-2. 성능 평가 — 비교와 이동
- 시간 복잡도 평가 시 **루프 제어 변수 증가는 세지 않는다**. 정렬의 기본 연산은 **비교(Comparison)** 와 **이동(Move)** 이다.
- 💡 **[출제] Swap = 이동 3번**: 두 값 A, B를 맞바꾸려면 **임시 변수 temp가 반드시 필요**하며 총 **3번의 저장(이동)** 이 발생한다.
  ```
  temp = A   // ① A를 temp에
  A = B      // ② B를 A에
  B = temp   // ③ temp를 B에
  ```

## 2. 기본 정렬 (O(N²))

### 2-1. 선택 정렬 (Selection Sort)
- **원리**: 전체를 '정렬된 그룹 + 정렬 안 된 그룹'으로 본다. 안 된 그룹에서 **최소값을 찾아 그 그룹 맨 앞과 교환(Swap)**, 정렬된 그룹에 편입. 이를 **N−1번** 반복.
- **비교 횟수**: (N−1)+(N−2)+…+1 = **N(N−1)/2 → O(N²)**.
- **이동 횟수**: 단계마다 1번 Swap = 3 이동, 총 **3(N−1)**.
- **시간 복잡도**: 최고차항만 보는 빅오로 **O(N²)**. **안정성 불만족(불안정)**.

### 2-2. 버블 정렬 (Bubble Sort)
- **원리**: 인접한 두 값을 비교해 앞이 크면 뒤로 보낸다(Swap). 거품이 떠오르듯 이동한다 하여 버블. 1단계 끝나면 **가장 큰 값이 맨 뒤**로 → **정렬된 그룹이 뒤에서부터** 형성.
- **비교 횟수**: 선택 정렬과 동일하게 항상 **N(N−1)/2**.
- **이동 횟수(최악)**: 역순이면 비교마다 100% Swap → **3 × N(N−1)/2**.
- 🗣️ **교수님 코멘트**: 이동이 많아 매우 비효율적이라, 논문에서 내 알고리즘을 돋보이게 하려고 일부러 **성능 나쁜 비교 대상(related work)** 으로 끌고 오기도 한다는 농담.

### 2-3. 삽입 정렬 (Insertion Sort)
- **원리**: '정렬된 그룹 + 안 된 그룹'. 안 된 그룹의 첫 데이터를 뽑아 **정렬된 그룹의 올바른 위치에 삽입**. 자리를 만들려고 정렬된 데이터를 뒤로 한 칸씩 **민다(Shift)**.
- 💡 **Swap 대신 Shift**: 선택·버블은 무조건 Swap(이동 3번)이지만, 삽입은 ① 타겟을 임시변수에 빼고(이동 1) ② 큰 값들을 한 칸씩 밀고(이동 1씩) ③ 제자리에 넣는다(이동 1) → **이동 횟수를 줄일 수 있다**.
- **성능**: **최선(이미 정렬) O(N)** — 앞 값과 1번만 비교. **최악(역순) O(N²)**. 대부분 정렬된 데이터에 매우 효율적.

## 3. 효율적인 정렬 (O(N log N))

### 3-1. 퀵 정렬 (Quick Sort)
- **분할 정복(Divide & Conquer)**: 대상을 반으로 쪼개 정복. **평균적으로 가장 빠른** 정렬.
- **작동(피벗·포인터)**:
  1. **피벗(Pivot)** 설정(보통 맨 앞).
  2. 왼쪽(Low)은 오른쪽으로 가며 **피벗보다 큰 값**, 오른쪽(High)은 왼쪽으로 가며 **피벗보다 작은 값**을 찾아 둘을 **교환**.
  3. 두 포인터가 **엇갈리면(Low > High)** 멈추고, **High가 가리키는 값과 피벗을 교환** → 피벗 위치 확정.
  4. 피벗 왼쪽은 작은 값, 오른쪽은 큰 값으로 분할. 쪼갤 수 없을 때까지 **재귀** 반복.
- **시간 복잡도 유도(교수님 강조)**: N개를 둘로 나누며 N번 비교(상수 c).
  - T(N) ≤ cN + 2·T(N/2) ≤ 2cN + 4·T(N/4) ≤ 3cN + 8·T(N/8) …
  - k번 반복 → k·cN + 2ᵏ·T(N/2ᵏ). N/2ᵏ = 1 시점에서 **2ᵏ = N → k = log₂N**.
  - 따라서 **O(N log₂N)** (로그 선형). N이 커질수록 O(N²)와 격차가 급격히 벌어진다.
- 💡 **[출제] 최악의 경우 O(N²)**: 피벗이 매번 **최소 또는 최대값**으로 뽑히면 리스트가 반이 아니라 **1개와 N−1개**로 나뉜다 → 분할 이점을 잃고 선택/버블처럼 동작 → **O(N²)**. (방지: **중간값(median)** 을 피벗으로 선택.)

### 3-2. 힙 정렬 (Heap Sort)
- 💡💡 **[초특급 출제 예고] 힙 = 완전 이진 트리(Complete Binary Tree)!** 교수님이 직접 출제를 예고한 명제.
- **힙 정의**: 부모 값이 자식 값보다 **큰(또는 작은) 완전 이진 트리**.
  - **Max Heap**: 부모 ≥ 자식 → **루트에 항상 최대값**.
- **배열 저장(1-인덱스)**: 부모 ⌊i/2⌋, 왼쪽 자식 2i, 오른쪽 자식 2i+1. (트리지만 인덱스 계산이 편해 배열이 효율적.)
- **구성(삽입, Up-heap)**: 새 값을 **마지막 레벨 맨 오른쪽**에 넣고 부모와 비교해 더 크면 위로. 시간 = 트리 높이 **O(log₂N)**.
- **삭제·정렬(Down-heap)**:
  1. 삭제는 항상 **루트(최대값)** 를 제거 → **배열 맨 뒤로** 보낸다(이게 정렬되는 과정).
  2. 빈 루트에 **마지막 노드**를 끌어올린다.
  3. 새 루트를 **더 큰 자식**과 비교하며 아래로 내려 힙 재구성(Adjust).
  - 이 삭제+재구성을 **N번** 반복하면 오름차순 정렬 완성.
- **성능**: 트리 높이 log₂N, N개 삭제·재구성 → **O(N log₂N)** (평균 = 최악 동일).

## 4. 기타 정렬 알고리즘

### 4-1. 셸 정렬 (Shell Sort)
- 삽입 정렬의 단점(데이터가 많이 이동)을 보완.
- 일정 **간격(Gap, h)** 떨어진 자료끼리 부분집합을 만들어 삽입 정렬. h는 **원소 수의 1/2**로 시작해 단계마다 반으로 줄여 **h=1**까지 반복.

### 4-2. 머지 정렬 (Merge Sort)
- 퀵처럼 **분할 정복**. 리스트를 크기 1이 될 때까지 정확히 반으로 **분할(Divide)** 후, 정렬하며 다시 **결합(Combine)**. **외부 정렬**에 주로 사용.

### 4-3. 기수 정렬 (Radix Sort)
- 💡 **비교를 하지 않고 정렬하는 유일한 알고리즘!**
- **원리**: 자리수(Radix)별로 데이터를 **버킷(Bucket)** 에 넣었다 빼기를 반복(1의 자리 → 10의 자리 …).
- **버킷 = 큐(Queue)**: 선입선출이라 큐로 구현(10진법이면 큐 10개).
- **시간 복잡도 O(d·N)** (d = 최대 자리수). 비교 정렬 한계 O(N log N)보다 빠를 수 있음.
- **단점**: 실수·한글·한자 등은 불가. **동일 길이의 숫자나 단순 알파벳**에만 적용.

## 5. 📊 정렬 알고리즘 비교표 (암기)

| 정렬 | 평균 | 최악 | 최선 | 추가 공간 | 안정성 | 핵심 |
|---|---|---|---|---|---|---|
| 선택 | O(N²) | O(N²) | O(N²) | O(1) | 불안정 | 최소값 선택·Swap, 이동 3(N−1) |
| 버블 | O(N²) | O(N²) | O(N²)* | O(1) | 안정 | 인접 Swap, 큰 값 뒤로 |
| 삽입 | O(N²) | O(N²) | **O(N)** | O(1) | 안정 | Shift, 거의 정렬 시 최강 |
| 셸 | O(N¹·⁵)~ | O(N²) | O(N) | O(1) | 불안정 | 간격 h 부분 삽입 |
| **퀵** | **O(N log N)** | O(N²) | O(N log N) | O(log N) | 불안정 | 분할정복·피벗, 평균 최강 |
| **힙** | **O(N log N)** | **O(N log N)** | O(N log N) | O(1) | 불안정 | 완전 이진 트리 |
| 머지 | O(N log N) | O(N log N) | O(N log N) | O(N) | 안정 | 분할정복, 외부 정렬 |
| 기수 | O(d·N) | O(d·N) | O(d·N) | O(N) | 안정 | 비교 안 함·버킷(큐) |

\* 버블은 강의 기준(기본형) 비교가 항상 N(N−1)/2라 최선도 O(N²). (Swap 발생 시 종료하는 개선형은 최선 O(N).)

## 6. ✅ 13차시 최종 암기 체크리스트

- [ ] **Swap = 이동 3번**(temp 필요: temp=A, A=B, B=temp)
- [ ] 선택 정렬: 비교 N(N−1)/2, 이동 3(N−1), **불안정**, O(N²)
- [ ] 버블 정렬: 비교 항상 N(N−1)/2, 최악 이동 3·N(N−1)/2(역순), 큰 값이 뒤로
- [ ] 삽입 정렬: **Shift**(Swap 아님), **최선 O(N)**(거의 정렬), 최악 O(N²)
- [ ] 퀵 정렬: 분할정복·피벗, 유도 2ᵏ=N → k=log₂N → **O(N log N)**
- [ ] 퀵 **최악 O(N²)**: 피벗이 최소/최대 → 1:(N−1) 분할 (방지=중간값 피벗)
- [ ] **힙 = 완전 이진 트리**(출제 예고), Max Heap 루트=최대, 배열 1-인덱스(부모 i/2, 좌 2i, 우 2i+1)
- [ ] 힙 정렬: 루트 삭제→맨 뒤, 마지막→루트, Down-heap, N회 → **O(N log N)**(평균=최악)
- [ ] 셸=간격 h 삽입 보완 / 머지=분할정복·외부 정렬 / **기수=비교 없는 유일**·버킷은 큐·O(d·N)
- [ ] 그래프 보강: MCST 시작점 팁, 다익스트라 선택순서 ≠ 경로순서, 추이적 폐쇄 = 인접행렬 **N−1번 곱**

💪 정렬 8종 시간복잡도·안정성 표 + 힙=완전이진트리 + 퀵 최악 조건만 확실하면 정렬 파트는 끝!
