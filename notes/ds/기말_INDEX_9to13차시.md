## 🎯 기말 핵심 출제 영역 총정리

### 🌟 9차시 (트리·BST) — 기말 1번 확정
> 🗣️ **교수님**: "오늘 오신 분들은 **기말고사 1번 문제는 다 맞습니다.** 1번이 바로 트리 탐색입니다!"
- **트리 탐색 4종**: 전위(V→L→R, Prefix)·중위(L→V→R, Infix)·후위(L→R→V, Postfix)·레벨(큐 사용). 복사=후위, 비교=전위.
- **BST 삭제 3 Case**: 자식 0개(삭제)·1개(끌어올림)·**2개(왼쪽 서브트리 최댓값 또는 오른쪽 서브트리 최솟값)**.
- **BST vs Heap 구분** (기말 출제 예고): BST=L<Root<R(검색·중위정렬), Heap=완전 이진트리+부모≥자식(우선순위 큐·O(1) 최값).
- **이진트리 수학**: 레벨 i 최대 2^(i−1), n노드 간선 n−1, 포화 트리 2^h−1, 최소 높이 ⌈log₂(n+1)⌉.
- **쓰레드 이진트리**: NULL 링크 n+1개 재활용, 왼쪽 NULL→선행자·오른쪽 NULL→후속자, 플래그로 구분.

### 🌟 10차시 (히프)
- 🗣️ **교수님**: "힙을 만들 때는 **무조건 완전 이진 트리**를 만들어야 한다는 생각을 꼭 하셔야 돼요!"
- **삽입(Up-heap)**: 값과 무관하게 **마지막 빈자리부터 채운 뒤** 부모와 비교해 위로 올림. (값이 작아서 왼쪽 가는 게 **아님**.)
- **삭제(Down-heap)**: 루트 제거 → 마지막 원소를 루트로 → 더 큰 자식과 비교하며 아래로 내림.
- **1-인덱스 공식**: 부모 ⌊i/2⌋, 왼쪽 2i, 오른쪽 2i+1. (9차시 0-인덱스 트리 공식과 **혼동 금지**.)
- 🗣️ **교수님(기말 예고)**: 데이터 (21,12,33,14,25,36,7,28,39,10)로 BST·탐색·Max Heap·삭제 트레이싱.

### 🌟 11차시 (그래프 I·표현·탐색)
- **adjacent(v) 연산** (출제 확정): 정점 v에 인접한 정점 리스트 반환 — 탐색 시 '다음에 어디로'를 결정.
- **오일러 경로 조건**: 모든 정점 연결 + 차수 홀수 정점 2개 이하. (쾨니히스베르크: 차수 5,3,3,3 → 불가)
- **완전 그래프 간선 수**: 무방향 n(n−1)/2, 방향 n(n−1).
- **DFS=스택**(갈 때까지)·**BFS=큐**(인접부터). 🗣️ **교수님**: "큐에는 **무조건 작은 숫자를 먼저** 넣는다." (BFS 트레이싱 함정)
- **표현**: 인접 행렬(정적·무방향이면 대칭)·인접 리스트(동적).
- 🗣️ **교수님**: 신장트리·최소신장트리·최단경로에 "**별표를 치세요**" (12차시 알고리즘).

### 🌟 12차시 (그래프 II·MST·최단경로) — 손풀이 출제 확정
> 🗣️ **교수님**: "1) DFS/BFS 탐색, 2) Kruskal·Prim, 3) Dijkstra 거리 갱신은 반드시 **직접 손으로 그려가며** 연습하세요."
- **신장트리**: 모든 정점 연결 + 사이클 없음 + |E| = n−1. **완전 그래프 신장트리 수 = n^(n−2)** (n=4 → 16).
- **MST — Kruskal**(간선 기반): 가중치 오름차순, 사이클 생기면 버림. **Prim**(정점 기반): 트리에 인접한 최소 간선 정점 추가.
- 🗣️ **교수님 팁**: 가중치 동률이면 **알파벳 앞·작은 숫자 정점** 우선.
- **Dijkstra**: 🗣️ "**돌아가더라도 가중치 합이 작으면 우회 경로를 선택**한다." distance 벡터 단계별 갱신(Relaxation) + 선택 정점 보이기.
- **추이적 폐쇄**: i→j 도달 가능성(Reachability)을 행렬 A⁺로 표현.

### 🌟 13차시 (정렬) — 정렬 8종 표·힙·퀵 최악
- 💡 **Swap = 이동 3번**(temp 필요). 선택: 비교 N(N−1)/2·이동 3(N−1)·불안정 / 버블: 비교 항상 N(N−1)/2·최악 이동 3·N(N−1)/2 / 삽입: Shift·**최선 O(N)**.
- **퀵**: 분할정복·피벗, 유도 2^k=N → k=log₂N → O(N log N). 💡 **최악 O(N²)**: 피벗이 최소/최대 → 1:(N−1) 분할(방지=중간값 피벗).
- 💡💡 **힙 = 완전 이진 트리**(출제 예고). Max Heap 루트=최대, 1-인덱스(부모 i/2·좌 2i·우 2i+1), 삭제(루트→뒤·마지막→루트·down-heap) N회 → O(N log N).
- **기수 = 비교 없는 유일** 정렬(버킷=큐, O(d·N), 실수·문자 불가). 머지=분할정복·외부 정렬, 셸=간격 h 삽입 보완.
